## 0. 一句话结论

KL 算子按定义正确实现并通过全部数值核验；**方向 A 的核心假设 H1（错误 Depth 造成可观察的任务损害）在 496 图确认中不成立**——孔洞破坏深度后，完整 signed Depth 项仍然**净有益**（相对完全关闭为 +1.45pp），因此有界干预（A / clip / gate）在 clean 与 holes75 上均为小幅负收益。A 唯一稳定可测的优势是**同等可行域下附带损害显著小于两种简单有界方法**（clean 上为 clip 的约 1/8），但未找到与之对应的收益场景。

核心实现要点（与计划第 13.3 节逐条对应）：

- 最小化 $D_{KL}(p \,\|\, p^D)$，可行域 $e^{-\tau}p^0_j \le p_j \le e^{\tau}p^0_j$，用**共同归一化因子** $c$ 在 log 域对 $z=\log c$ 做向量化二分求根；输出 $p=\exp(\log p^*)$ **直接用于聚合**，不做「裁剪后重新归一化」，不把 $p^0$ 截断到 epsilon。
- 保留原始 signed Depth bias：`b = Bd - max(Bd)` 只做行常数平移，`r = b - logsumexp(l0 + b)` 数学上等于 $\log(p^D/p^0)$。
- 保留 W/H 共享原 Q/K：H 只用原 `qr/kr` 重排，**不从 W 输出重新生成 Q/K**，也不让 H 重新使用原 V；W 聚合结果以 FP32 进入 H。
- A/O/OFF/C/G 共用同一 $p^0$ 定义、同一 signed $Bd$ 构造与同一 FP32 聚合协议；子模块输出在 `+ lepe / out_proj` 前转回 `lepe.dtype`。
- 未新增可靠性预测器、Depth 分支、辅助损失或可学习参数；`state_dict` 键集合不变（802 键），`strict=True` 可加载 R2 完整权重。

研究控制是模块上的**普通非参数属性**（`block.influence_control` / `attn.influence_control`），在 `model.training` 或启用梯度时**主动报错**，防止未经验证被误用于训练。

## 2. 数值与兼容性核验（实测）

### 2.1 内置算子自检（CPU，`--phase self-check`）

17/17 通过，见 `outputs/influence-sun-diagnostic/20261013-influence-a/` 同源日志。关键项：

- 手算样例 $p^0=(.5,.3,.2)$、$p^D=(.8,.1,.1)$、$\tau=\ln 2$ → $p^*=(.75,.15,.10)$，$c=0.9375$；FP64 深求解偏差 $1.1\times10^{-16}$，默认 24 次二分偏差 $2.76\times10^{-8}$。
- 反例核验：先逐项裁成 $(.8,.15,.1)$ 再除以 1.05 会重新低于第 2/3 项下界 → 确认「裁剪后归一化」不是投影。
- $\tau=0$ 返回 $p^0$；单 key 归一化；已可行行原样返回 $p^D$；常量 $Bd$ 投影回 $p^0$；`depth_off` 等于 $\mathrm{softmax}(qk+bs)$；`original` 等于 $\mathrm{softmax}(qk+bs+bd)$。
- `kl`/`clip`/`gate` 归一化误差 $7.2\times10^{-7}$/$2.4\times10^{-7}$/$2.4\times10^{-7}$，倍率超界 0，无 NaN/Inf；三者互不相同（$|p^{A}-p^{C}|=0.274$）。
- NaN 输入被拒绝。

### 2.2 真实行在线统计（pilot32 前 4 张图，29 块 $\times$ 2 轴，合计 **1.63e9 个键**）

| 指标 | original | A (kl) | clip | gate |
| --- | --- | --- | --- | --- |
| 最大归一化误差 | 6.0e-7 | **5.96e-7** | 5.96e-7 | 5.96e-7 |
| 倍率超界率 | 2.03e-1（观测对象） | **0** | **0** | **0** |

- **归一化误差 5.96e-7 ≤ 1e-6**，24 次二分深度足够，无需改 32/48 次。
- **A/C/G 的倍率超界率恒为 0**；`original` 的 20.3% 是「完整 signed Depth 真的超出单倍预算」的观测结果，按计划不作为实现失败。
- $\mathrm{KL}(p\|p^D)$：**A 最小**（3.3e-4 < clip 8.1e-4 < gate 8.3e-4），与 A 的数学定义一致。
- 尾部：$p^0<10^{-6}$ 的键占 6.8%；出现 $p=0$ 且 $p^0>0$ 的比例为 **0**（无 underflow 造成的零概率质量损失）。
- **4.94% 的注意力行在 $\tau=\ln 2$ 下至少有一个键超预算**（$\ln 4$ 下为 1.83%）——存在可观测的超预算几何关系。

### 2.3 legacy 兼容与精度基线

- 关闭控制后 legacy 路径**逐位可复现**（两次前向差 0.0）。
- 32 图前 4 张上，共同 FP32 `original` 与 legacy 的 argmax 一致率 **0.9995–0.9999**，`max|Δlogit|` 1.5e-2–2.3e-2。差异来自 `log_softmax+exp` 与 `softmax` 的浮点路径，不作为结论依据。
- 分块一致性：`--query-chunk` 取 0 / 7 / 12 时整网输出**逐位相同**。
- 关键旁证：`depth_off` 在 clean / holes75 / cyclic16 三条件上输出**完全相同**（mIoU 39.1662，逐位一致），证明控制只影响 $Bd$，未泄漏到空间项或其它分支。

## 6. 对验收问题（计划第 13.8 节 / 指令第七节）的回答

1. **KL 算子是否正确实现、数值与兼容性是否达标？**
   是。最小化方向、共同归一化因子、双向下界、特殊路径均按定义实现；17 项自检通过；真实 1.63e9 个键上最大归一化误差 5.96e-7、A/C/G 倍率超界率 0、$\mathrm{KL}(p\|p^D)$ 为三者最小；legacy 逐位可复现，`strict=True` 加载 R2 权重且 `state_dict` 键数不变。

2. **错误 Depth 是否造成可观察的注意力关系改变与任务损害？**
   关系改变：**是**——4.94% 的注意力行在 $\tau=\ln 2$ 下超出单倍预算，且 OFF 与 O 的输出差异显著（clean 上 −3.94pp）。
   任务损害：**否**——在 75% 孔洞下完整 signed Depth 项仍然净有益（相对 OFF 为 +1.45pp，528 图）。即被破坏的深度输入没有造成净损害，只是收益从 +3.94pp 缩小到 +1.45pp。

3. **KL 投影能否改善分割结果及区外错误？**
   否。528 图上 clean −0.134pp、holes75 −0.124pp；496 图区外新增错误由 3.554% 升至 3.702%（A 是所有干预里升幅最小的，但仍为负）。

4. **与有界 clip、自适应有界 gate 相比是否存在独立收益？**
   任务结果上没有正收益可比；三者都是小幅负收益。A 存在**独立且可测的机制差异**：在相同 $\tau$ 与相同可行域下，A 对原几何分布的附带改变最小（$\mathrm{KL}(p\|p^D)$ 3.3e-4 vs 8.1e-4/8.3e-4），对应的 clean 任务损害最小（−0.134pp vs −1.097/−1.048pp）。**但这是「损失更小」，不是「收益」**，且没有找到需要限制几何影响的使用场景——因为被约束的极端关系本身并不造成净损害。

5. **clean 性能代价、实际 GPU 成本？**
   clean 代价 −0.134pp（A，528 图），相对两种简单有界方法小约 8 倍。GPU 合计约 34.0 分钟、峰值显存 740 MB。

6. **是否建议进入三组 10 epoch 短程训练？**
   **本执行模型建议：不建议**（最终裁决交主力模型）。依据：496 图与 528 合并结果中，A/clip/gate 在所有条件上均为负收益，没有可放大的正向信号；H1 不成立说明不存在「需要修复的损害」。此外计划第 7.2 节的短训增强选用非循环 16 像素平移，而该扰动已被证明不产生实质损害（0.2% 量级），三组短训将缺乏区分度（见第 7 节）。

## 7. 局限、未运行项与需要裁决的矛盾

**局限**

- 全部为**冻结权重**诊断，`model.eval()` 下前向推理；冻结权重可能尚未适配投影，本结果不是联合训练的性能上限。
- mIoU 为按类平均，32 图子集波动大（已在 4.1 说明）；本报告以 496 / 528 图结果为准。
- 区域统计按像素合并和按图宏平均在本报告中以像素合并为主，逐图方向与计数保留在 `regions.csv` / `tasks.csv`。
- 天然 raw0 的物理语义仍未建立；本报告只做受控输入扰动，未使用任何推理侧可靠性标签。
- `Correspondence16` 的 496 图部分未运行（原因见下），该条件只有 32 图结果。

**未运行项**

- 反向传播、梯度核验、任何训练入口或训练运行（第一阶段明确不含）。
- 正式 test 划分、NYUv2、DeLiVER、云端或付费资源。
- 未加入孔洞/噪声等训练增强；未做多 seed 训练。

**需要主力模型裁决的两处矛盾**

1. **H1 与实测矛盾**：计划假设「错误 Depth 造成可观察的任务损害」，实测显示孔洞下完整 Depth 项仍净有益（+1.45pp）。若坚持该假设，需要新的观测设计（例如只统计超预算行对应的像素子集，或引入真实的传感器错配），而不是继续堆扰动强度。
2. **短训增强设计与实测矛盾**：计划第 7.2 节要求三组短训使用「已复核的非循环、非零有效区域平移」作为统一增强，但该扰动在本次诊断中不造成实质损害（$C_\Delta$ 内新增错误仅 0.2%）。若沿用该增强，三组短训预期无区分度；若改用 Holes75，则与计划「评价保留 Holes75 作为未训练故障」的设定冲突。这两条路径都需要上级重新裁决后才能启动短训。
