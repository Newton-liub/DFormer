# 07：A2 正式筛查工具扩展计划

> 任务类型：A2 数据扰动、推理和统计工具升级。
>
> 模型要求：Terra 可实现；**Sol 必须复核实验协议、统计口径和 test 封存。**
>
> 本阶段只改工具并用夹具/小样本验收，不运行正式 A2。

## 1. 前置与数据角色

- 05 已冻结三个 development best checkpoints。
- A2 开发筛查使用 val-dev；official test 不用于触发 B2。
- 06 baseline test 结果不得反馈到 A2 条件或阈值。
- 历史 `tools/mve/a2_*` 和 16 图结果保留，只升级不覆盖历史证据。

## 2. 正式 A2 因素

至少支持：

- 样本：val-dev 全集优先；资源受限预审至少固定 64 图。
- q：`0, 0.1, 0.3, 0.5`。
- mask type：`block`、`random`。
- fill type：`zero`、该图有效深度中位数负对照。
- mask seeds：至少 2 个固定值。
- model seeds：05 的 3 个 development checkpoints。
- 注入区域：只允许原始 `Depth16 > 0` 像素。

正式因素在运行前由 Sol 写入 A2 protocol manifest；Terra 不增删条件。

## 3. 建议改造文件

- 扩展 `tools/mve/a2_prepare_masks.py`
- 扩展 `tools/mve/a2_run_sensitivity.py`
- 扩展 `tools/mve/a2_evaluate_results.py`
- 扩展 `tests/test_a2_masks.py`
- 新增统计、checkpoint/manifest、输出冲突等测试
- 必要时新增只做 orchestration 的 `tools/mve/run_a2_matrix.py`

避免把所有逻辑塞进一个脚本；mask 生成、模型推理和离线统计保持可独立重跑。

## 4. manifest 与输出身份

condition ID 至少包含：

- sample ID、model seed/checkpoint SHA；
- mask seed、mask type、fill type、q。

manifest 至少记录：

- schema/protocol、完整 commit；
- val-dev 路径/数量/SHA；
- checkpoint 路径/SHA/seed/best epoch；
- RGB/Depth/Depth16/Label 路径规则；
- 图像尺寸、归一化、RGB/BGR、eval scale、flip/sliding/MST；
- 每条件目标和实际注入像素数；
- 生成命令和工具版本。

输出目录存在时默认拒绝，禁止多个条件共享预测路径。历史曾发生并行输出冲突，因此正式工具不得依赖不安全并行写入。

## 5. mask 与填充语义

- q 分母是原始有效像素数；q=0 不修改 Depth。
- block/random 都必须精确或在记录的离散误差内达到目标像素数。
- mask 只能是原始有效集子集。
- zero 将选中 8-bit Depth 像素置 0。
- median 使用该图原始有效深度的中位数填充同一 mask，作为“信息删除”负对照。
- 同 sample/q/seed 的 zero 与 median 必须复用完全相同 mask。
- 所有随机过程使用局部 RNG，不能依赖全局未记录状态。

## 6. 推理严格性

- checkpoint 必须严格校验预期 model keys；missing/unexpected keys 视为 error，不能只 warning 后继续。
- q=0 的预测和指标必须与独立 baseline evaluator 在相同设置下等价。
- 模型权重固定，不调用 optimizer，不写 checkpoint。
- 每个条件保存足够离线重算的预测和最小元数据；不重复保存大型输入数据。
- official test 路径若出现在 A2 development命令中立即失败。

## 7. 统计输出

每图和聚合至少报告：

- foreground mIoU；
- `ΔmIoU(q)=mIoU(q)-mIoU(q=0)` 的同图配对差；
- 配对差为负的图像比例；
- 注入区域及向外固定边界带 mIoU；
- model seed、mask seed 分层；
- block/random、zero/median 对照；
- 自然无效深度比例高/低分层；
- bootstrap 置信区间或冻结的等效区间方法。

统计脚本只读预测和 manifest，允许不重新跑 GPU 独立重算。

## 8. Terra 测试矩阵

- block/random 的目标计数、有效集子集和确定性。
- q=0 mask 为空、输入字节不变。
- zero/median 复用同 mask且填充值正确。
- 同 seed 重现，不同 seed 在可行样本上不同。
- condition ID 唯一；输出碰撞、重复 manifest、缺预测快速失败。
- 相对路径可移植，移动结果目录后仍能解析。
- checkpoint 键缺失/额外、SHA 不符时失败。
- q=0 与 baseline evaluator 的 logits/预测/指标等价夹具。
- 配对 Δ、负差比例、分层和 bootstrap 在手工小矩阵上正确。
- 预期条件数、CSV 行数、JSON 聚合和预测数闭合。

## 9. 验收和提交

1. Terra 完成工具和测试，运行 compile、`python -m pytest -q tests`、diff check。
2. 用极小合成/真实样本 dry run，不执行正式矩阵。
3. Sol 审核 q、负对照、统计、checkpoint 严格性和 test 封存。
4. 单独提交，推荐标题：`扩展 MUSeg A2 正式敏感性筛查工具`。
5. 提交不包含预测、mask 大产物或 checkpoint。

## 10. 完成标准

- A2 正式矩阵可由 manifest 唯一重建。
- q=0 与 baseline evaluator 等价。
- 多 model/mask seed、两类 mask、两类 fill 和统计全部有测试。
- official test 在开发工具中被明确拒绝。
- Sol 签署工具，允许进入 08。
