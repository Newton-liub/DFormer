# 10：B2 实现、链路集成与零训练筛选计划

> 任务类型：按 09 冻结规格机械实现并做零训练 B0/B2 对照。
>
> 模型要求：Terra 可实现外围和按规格编码；**Sol 必须逐行复核 validity 下采样、pair mask 和 GeoPriorGen 核心改动。**

## 1. 前置条件

- 08=A2-G 且用户批准。
- 09 的接口、shape、伪代码、金标准和允许修改范围已签署。
- B0 development checkpoint、val-dev、A2 manifest 和所有 SHA 已冻结。

## 2. 建议实现边界

按 09 允许范围，预计涉及：

- 数据集读取 `Depth16` validity；
- train/val/infer 几何增强同步 validity；
- dataloader batch 增加明确字段；
- `utils/train.py`、`utils/val_mm.py`、`utils/eval.py`、`utils/infer.py` 参数透传；
- `models/builder.py::EncoderDecoder` 可选 validity 参数；
- `models/encoders/DFormerv2.py` backbone/stage/`GeoPriorGen`；
- 配置开关，例如 `depth_validity_gating=false|true`；
- 单元、集成和兼容测试。

不得修改 decoder、类别映射、safe loss、B0 权重、优化器或 A2 判据。

## 3. Terra 实现顺序

1. 先把 09 的金标准测试落地，使生产实现前测试失败。
2. 实现数据端 validity 读取和同步增强，先通过数据测试。
3. 实现可选参数的端到端透传，B2=false 时所有现有测试通过。
4. 按 full GSA 金标准实现，再按 decomposed GSA 实现；每步独立测试。
5. 添加 strict checkpoint 兼容、参数量和 state dict 测试。
6. 添加真实小 batch forward/backward。
7. Sol 逐行审查核心几何；未签署前不得 GPU 正式筛选。

## 4. 必须通过的验收

### 数据链路

- validity 精确等于对应增强后 `Depth16 > 0`；nearest resize、invalid padding。
- RGB/Depth/Label/validity 的 crop/flip/scale 参数一致。
- batch>1 不串样本；A2 注入正确更新 validity。

### 几何行为

- all-valid B2 与 B0 decay/logits 等价。
- all-invalid 仅保留 positional decay。
- mixed pair 按 09 手算值精确 gating。
- full 与 decomposed、非方形、多 head、AMP 全覆盖。
- 参数量、state-dict key 不变，旧 checkpoint strict load。
- forward/backward finite，吞吐和显存增量记录。

### legacy 回归

- B2=false/validity=None 的 MUSeg、NYU、SUNRGBD 现有路径不变。
- `python -m pytest -q tests`、compile、diff check 通过。
- 真实 B1 混合 batch 回归仍通过。

## 5. GPU 集成 smoke test

- 使用极小步数分别运行 B0 和 B2，同 batch/seed/样本。
- 检查 loss finite、AMP、显存、吞吐和 checkpoint strict load。
- 该 smoke 不是 B2 效果证据。
- 性能/显存超出 09 预期时停止，由 Sol 判断是否接受，不擅自优化几何。

## 6. 零训练 B0/B2 筛选

- 使用同一个冻结 B0 checkpoint；B2 不更新任何权重。
- 在同一 val-dev、同一 A2 mask/seed/q/fill 条件下分别运行 B0 与 B2。
- q=0、corruption 条件、自然无效率分层全部配对。
- 保存 B0/B2 logits/预测所需证据和独立统计；输出目录隔离。

### G0 通过条件

至少同时满足：

- `q=0.3 block zero` 上，B2 相对 B0 恢复至少 1.0 个 mIoU 百分点；
- q=0 干净条件下降不超过 0.5 个百分点；
- 多 model/mask seed 方向一致；
- 没有 strict load、数值、显存或吞吐不可接受问题。

未达到即 B2-N-G，停止 11，不通过反复改 gating 追结果。
