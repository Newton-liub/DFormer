## 2. 最少需要知道的事实

- 当前基础模型是 **DFormerv2-S RGB Quick-B0**，最终 checkpoint 为 epoch 420，SHA-256 为 `f246a3afc50334c81302b7bfebdadf7cf37d00326bf1c3aa54f6a151754e3a1c`。
- 正式 A2 只使用冻结的 318 条 `val-dev`；official test 保持 `sealed_unread`。
- A2 不更新权重，只在有效 Depth 区域注入预注册 corruption，并测量冻结 B0 的响应。
- 历史 epoch-10、16 张 official-test pilot 不是正式 A2，不能作为进入 B2 的门票。
- B1 `safe_masked_mean` 固定保留；A1/B1 的标签有效像素数值稳定性问题与 A2/B2 的深度有效性问题是两条独立问题链。
- B2 当前尚未实现。只有 `A2-pass + 用户明确批准` 才能开始其生产规格和实现。
- 人工 corruption 可以触发工程开发；自然无效深度分层不足时，只能把结论限定在人工条件，不能声称真实缺失机制或部署收益。
- B2 的零训练验证不等于训练后性能结论；短训、完整独立训练和 paired screening 不属于本小计划。

## 3. 当前任务卡

当前唯一方案是 [`02-A2正式验证与B2条件分支.md`](./02-A2正式验证与B2条件分支.md)。

**当前任务：任务 1“A2 协议与本地准备”。** 目标是：

1. 绑定当前 B0 checkpoint、`val-dev`、RGB/Depth 输入契约和原始 Label 网格 evaluator；
2. 冻结 `q`、mask 类型、fill 类型、mask seed、自然分层、paired 聚合和 `A2-pass/stop/inconclusive` 规则；
3. 实现 A2 corruption/evaluator 的独立入口和结构化 manifest；
4. 完成 `q=0` 等价、mask 只落在原始有效 Depth、zero/median 共用 mask、确定性、official-test 拒绝等最小 CPU 定点检查。

任务 1 不运行完整 A2，不产生 A2 研究裁决，也不授权 B2、GPU、训练、云资源或 official test。协议中的自然分层 cut-off、zero-vs-median 阈值和其他尚未由当前权威口径确认的细节，必须先作为“待确认”提交用户，不得从归档计划静默继承。
