## 3. 最少需要知道的固定身份

- 模型是 DFormerv2-S RGB Quick-B0，epoch 420 checkpoint SHA-256 为 `f246a3afc50334c81302b7bfebdadf7cf37d00326bf1c3aa54f6a151754e3a1c`。
- `val-dev` 有 318 条、196 个 location group，覆盖六个 mine，split SHA-256 为 `1d0719d8f64f016d48995c25ab66d4004d76b7155d9efeef7cbb7454c0dd0e83`；它已参与 checkpoint 选择，结果只能称为 development evidence。
- 原始 `Depth16` 是二维 `uint16`，`0` 为无效；现有模型输入使用固定映射 `round(Depth16 * 255 / 13932)` 形成 8-bit Depth。注入应发生在原始 Depth16 上，再统一走量化、归一化和 evaluator 链。
- 当前没有严格可比的 RGB-only checkpoint/logits；首轮不使用 RGB-only 回退。
- 主 evaluator 是 `msflip-whole-original-grid-v1`；新 MVE 必须另建 identity，但保持相同五尺度翻转和原始 Label 网格。
- official test 继续为 `sealed_unread`，本计划不得读取。

## 4. 本次原拟议任务卡

- **唯一交付物：** 在用户另行确认执行后，物化 `DVC-A1-valdev-boundary-zero-v2` protocol 与 138 组/218 样本 evaluation allowlist，并完成 v2 最小 preflight；完整五条件 GPU 评价仍需在 preflight 通过后再次确认。
- **输入：** v1 `mask-manifest.json`、冻结 `val-dev`、固定 checkpoint、原始 `Depth16`、RGB/Label、现有主 evaluator 和 Boundary IoU 定义。【文献依据：参考资料清单 P0-1、P0-5】
- **输出：** v2 protocol/allowlist 与哈希、组/图级构造性摘要、q=0 等价和 mask 定点证据；只有后续评价获批并完成时才生成配对指标和 `supported/not-supported/inconclusive/protocol-blocked` 裁决。
- **前置门禁：** 纳入规则只依赖 v1 mask 事实，不依赖模型输出；必须精确得到 138 组/218 张图，保持阈值 `0.05`、原 split 和 `official_test_included=false`。
- **停止条件：** allowlist 身份或数量不符、q=0 不等价、对照面积不匹配、非有限值、Boundary IoU 小例不符或用户尚未批准对应执行阶段时立即停止。
