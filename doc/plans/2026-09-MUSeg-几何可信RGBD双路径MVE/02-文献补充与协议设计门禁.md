## 1. 目标与完成结论

本门禁把摘要级动机补成足以收缩 MVE 的方法证据，并区分论文依据、项目事实和本项目预注册选择。P0-1 至 P0-6 已完成正文核对或明确删除/替代处置，P1 也已核对；资料详情见 [`参考资料/00-待补充论文内容清单.md`](./参考资料/00-待补充论文内容清单.md)。

门禁结论为 `reference-ready + scope-reduced`：资料足以规划二维问题验证，但不支持原草案中的三维评价、冻结 logits 门控或严格 RGB-only 回退。

## 2. 已冻结的文献裁决

1. DFormerv2 Depth 在四级 GSA 前形成 patch 级几何先验，退化注入必须与项目实际 Depth 链一致。【文献依据：P0-1，PR070】
2. PR029、PR089、PR090 的 confidence/fallback 都依赖端到端或专门缺失模态训练，只能作为方法动机，不能证明离线 logits 门控有效。【文献依据：P0-2、P0-3】
3. RE042 的 luminance-guided FGT-JBF 可复现但混入 RGB guidance，不作为首轮单变量 DVC 基线。【文献依据：P0-4】
4. Boundary IoU 使用 Cheng et al. 的对称 binary-mask 定义；MUSeg 多类 one-vs-rest、ignore、空类和 macro aggregation 需独立预注册。【文献依据：P0-5】
5. `RE447` 实际使用 AHP-FCE 和专家判断矩阵，不包含 paired/cluster bootstrap；从本计划统计证据链删除。【文献依据：P0-6】
6. PR117 的 integrity prior 依赖 ground truth/pseudo-depth 和训练；首轮只能采用简单有效率/梯度特征，不声称复现。【文献依据：P1-1】
7. PR053、RE049、RE053/RE188 分别未闭合标准 risk–coverage、MSP 0.9 高置信错误和米制三维评价；这些分支均不进入首轮。【文献依据：P1-2、P1-4、P1-5】

## 3. 不再额外寻找论文的通用流程

以下是本项目将明确预注册的常规分析操作，不再为了形式完整继续补文献：

- 同一图像各条件保持一一配对；
- 同一 location group 内样本只作为相关观测处理；
- 固定 seed、退化剂量、效应量、聚合顺序和置信区间算法后再查看结果；
- 对 location group 做有放回重采样，组内保留全部样本，计算 paired difference 的 percentile interval；
- 保存 manifest、哈希、命令、环境、退出码和失败记录；
- 先做小规模完整性检查，再在单独授权后做完整评价。

这些操作是项目 protocol，不写成论文共识，也不把 `RE447` 或其他邻近论文当作直接依据。若未来要引入复杂的层级模型、BCa 区间、序贯检验或多重比较，届时在子计划中用【需补参考文献】标记并重新过门禁。

## 4. 项目事实核对结果

- `val-dev` 为 318 条、196 个 location group，覆盖六个 mine；group key 是样本名的前四个连字符段。现有项目没有独立 sequence 或 near-duplicate key。
- `val-dev` 已参与 checkpoint 选择，因此不能再命名为独立评价集 `E`；首轮零拟合 DVC 直接使用全 `val-dev` 做 paired development evaluation，不强行二拆 `C/E`。
- `Depth16` 为二维 `uint16`，`0` 表示无效；模型输入 8-bit Depth 由固定全数据映射 `round(Depth16 * 255 / 13932)` 生成。
- evaluator 对 Depth resize 使用双线性，对 Label 不 resize；Label 原始 `0` 映射为 ignore `255`，仅评价 15 个前景类。
- DFormerv2 前向只取 Depth 的第一个通道，并在每一级 GSA 中双线性缩放后使用 patch 深度差。
- 历史 `tools/mve/a2_run_sensitivity.py` 的 `boundary_band_mIoU` 是 corruption mask 外围膨胀带上的普通 mIoU，不是标准 Boundary IoU；不得改名复用。
- 本地尚无已核验的逐样本相机内外参、Depth 物理单位和严格可比 RGB-only checkpoint，因此三维与 RGB-only 分支保持删除。
