## 1. 目标与假设

目标是把“摘要级研究动机”补成足以设计可复现 MVE 的方法与实验依据，并明确哪些阈值属于本项目预注册选择，而不是论文常数。

当前假设是：少量关键论文的定点章节足以解决方法定义、实现选择和指标口径问题，无需补充 230 篇全文。若补充内容仍不能回答项目特定事实，则下一步做本地代码/数据的最小只读核对，而不是继续扩大文献范围。

## 3. 最小交付物与完成判据

最小交付物是一份逐项可追溯的参考资料包。资料门禁只有同时满足以下条件才通过：

1. 清单中 P0 必须项均有正文摘录或明确的“不可获得 + 采用何种保守默认/删除该设计点”处置；
2. 每项都有论文身份、章节/页码和来源链接或 DOI；
3. 公式、图表、算法框的符号定义和必要上下文完整，不能只有截图标题或二手转述；
4. `RE447` 已被补齐、替换为可核验统计来源，或从草案证据链删除；
5. 明确区分“论文报告的方法/指标”和“本项目自行预注册的样本数、退化比例、阈值与停止规则”；
6. 补充内容足以决定三维分支、深度补全基线、边界指标定义和门控的最低复杂度实现是否保留。

## 4. 执行步骤

1. 用户按清单补充 P0 内容；P1 内容可选。
2. 逐篇核对题名、作者、年份、出版物、DOI/链接与原题录是否一致；CVPR 年份字段冲突必须以正式出版记录处置。
3. 将正文摘录映射到草案中具体设计点，不把论文没有给出的数值归因给论文。
4. 若一个设计点只有邻近领域依据，标明“方法迁移依据”，不能写成 MUSeg 或 RGB-D 语义分割直接证据。
5. 资料门禁通过后，定点核对 MUSeg 数据元信息、现有 RGB-only 身份和 Depth/evaluator 代码，冻结 shared protocol。
6. 先详细创建 `DVC-A1`；`DVG-B1` 只保留触发条件、交付物和不越界边界，等待 `DVC-A1` 证据后再细化。

## 5. 变量边界

本阶段只改变计划文档和参考资料内容。以下内容保持未冻结：

- `C/E` 的来源、样本数和 location/scene group 定义；
- 边界算子的阈值、带宽与无效像素采样策略；
- 深度补全算法及参数；
- Boundary IoU、深度边缘 F1、点到表面误差和风险—覆盖率的精确定义；
- `DVG-B1` 的质量分数、特征归一化、融合公式和模型容量；
- G/N-G 数值门槛、bootstrap 层级、次数、置信区间类型和多重条件裁决。

## 7. 合法终点与恢复方式

- `reference-ready`：P0 内容完整且来源可核验；恢复点是项目事实定点核对与 shared protocol 编写。
- `reference-blocked`：关键正文不可获得或身份冲突未解决；恢复点是清单中具体未完成项。
- `scope-reduced`：在无法获得资料时，经用户确认删除三维分支、特定补全法或可学习门控等依赖项，以更保守的二维 Oracle MVE 收缩。
- `protocol-blocked`：文献闭合但项目不存在独立数据职责、严格可比 RGB-only 输出或可复核 Depth 身份；停止，不临时训练或读取 official test 补洞。

失败时保留缺失项和来源冲突，不用摘要猜测正文，不为了形成完整计划而虚构公式或参数。
