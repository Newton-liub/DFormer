# 路径 B：全局温度缩放方案验证

> **实验状态：** 计划中，未执行。
> **实验类型：** 单参数、同源 logits、冻结模型的最小可行实验（MVE）。
> **上级计划：** [`../00-总方向规划.md`](../00-总方向规划.md)；双路径原方案见 [`../02-问题与方案双路径-MVE.md`](../02-问题与方案双路径-MVE.md)。
> **实时状态：** [`../../../../../main/MUSeg-current-status.md`](../../../../../main/MUSeg-current-status.md)。

## 1. 要回答的问题

在同一冻结 checkpoint、同一份 clean logits、同一 `C/E`、同一标签和同一有效像素掩码上，只拟合一个全局正温度 `T`，相对于未校准 Softmax，是否能在独立评价集 `E` 上改善概率可靠性？

核心假设是：`softmax(z/T)` 能改善预注册概率指标，同时保持逐像素 argmax、mIoU 和逐类分割预测不变。全局温度只学习一个标量，因此可将概率数值变化与分割预测变化分开。该假设需要直接的 temperature scaling 基础文献支持；当前 `RE136` 只能支持后验校准的邻近思路，不能承担这一方法依据。

## 2. 固定身份

- **模型：** 冻结的 `DFormerv2-S + ham`，MUSeg 15 类 RGB-D 语义分割；正式模型论文为 CVPR 2025 的 `DFormerv2: Geometry Self-Attention for RGBD Semantic Segmentation`。[RE006][RE429]
- **checkpoint：** epoch 420 `selector-epoch-420.pth`；SHA-256：`f246a3afc50334c81302b7bfebdadf7cf37d00326bf1c3aa54f6a151754e3a1c`。[PR001]
- **数据职责：** `C`（calibration，拟合温度和冻结阈值）与 `E`（evaluation，独立评价）必须来自独立、group-aware 的标注数据池。`val-dev` 已参与 B0 checkpoint 选择，不能作为正式独立 `C/E` 证据。[PR001][PR003][PR005]
- **同源输出：** Baseline 和温度缩放方案读取同一份 clean float32 logits、标签、ignore mask、样本顺序和 manifest，不重复推理。
- **官方测试：** 继续为 `sealed_unread`，不参与拟合、调参或评价。[PR001]

## 3. 运行前必须冻结

1. `C/E` 来源、location group 划分、样本清单和哈希；
2. 温度拟合目标（默认候选为有效像素 NLL）、`T>0` 参数化、搜索/优化范围、收敛和回退规则；
3. Baseline 与方法注册名：`uncalibrated_softmax`、`global_temperature_scaling`；
4. ECE 分箱、NLL、Brier、HCE、风险—覆盖和 AURC 的聚合方式；
5. 最小改善、置信区间、paired 重采样单位和 `supported/not-supported/inconclusive` 判据；
6. logits、标签、mask、checkpoint、protocol 和 evaluator manifest 身份。[PR003][PR004][PR005]

上述数值和约束目前均为**待确认**，不得根据 `E` 结果回调。

## 4. 实验步骤

1. **读取同源 clean logits。** 使用已经绑定 checkpoint、输入、evaluator 和 protocol 身份的 clean logits；Baseline 与方案不重新推理，也不改变样本过滤。[PR004][PR005]
2. **只在 `C` 拟合 `T`。** 以有效像素为单位按冻结的 NLL 目标拟合一个正标量，记录参数化、约束、收敛状态、回退规则和产物哈希；`E` 在拟合期间不可见。该步骤的 temperature scaling 直接方法来源待补充，`RE136` 仅作后验校准邻近背景。
3. **冻结并应用。** 在 `E` 上比较 `softmax(z)` 和 `softmax(z/T)`。两臂必须共享同一 logits、标签、ignore mask、样本顺序和评价实现。[PR004]
4. **计算最小 A/B 指标。** 报告 NLL、ECE、Brier Score、可靠性分箱、HCE 和风险—覆盖指标；同时比较逐像素 argmax、mIoU、逐类 IoU 和改变像素比例。[RE666][RE131]。这些指标的规范定义和 dense prediction 适配文献仍待补充。
5. **进行 paired 汇总。** 以图像或 location group 为重采样单位，报告方法差值和区间。若 ECE 改善但 AURC 不变，必须分别写成“概率数值改善”和“错误排序未改善”，不能合并为总体成功。[RE131][RE447]
6. **执行停止门禁。** logits 身份、样本过滤、mask 对齐、有限性、argmax 不变性或 official-test allowlist 任一失败时，标记 `protocol-blocked`，不解释指标。

## 5. 最简资源

- 已审计的 `C/E` clean float32 logits、标签、ignore mask 和 manifest；
- 普通 CPU 即可拟合一个温度并计算离线指标；不需要训练、反向传播或云资源；
- 两个离线方法注册项：`uncalibrated_softmax` 与 `global_temperature_scaling`。[PR004]

如果 logits 尚不存在，首次冻结模型推理仍需单独授权。

## 6. 判据与合法终点

### `B-solution-supported`

独立 `E` 上至少一个预注册概率指标达到最小改善，argmax 完全一致、改变像素比例为 0，mIoU 与逐类 IoU 在预注册容差内一致。具体改善比例和区间规则待任务 1确认；该判据的直接 temperature scaling 与 calibration 评价来源待补充。

### 增强证据

在相同覆盖率下选择性风险不升高，或在相同风险目标下覆盖率提高。这可以支持风险分数用途，但不能仅由 ECE 改善推出。[RE131][RE226]

### `B-solution-not-supported`

独立 `E` 上 NLL、ECE、Brier 均无稳定改善，至少一个主指标明显恶化，或 logits 身份、样本过滤、mask、argmax 契约失败。此时不直接升级到向量缩放、类别条件温度等高自由度方法。[PR005][RE447]

### `B-inconclusive`

概率指标、风险排序和迁移结果互相不一致，或统计不确定性无法支持二元裁决。应保留结果和恢复点，不通过调阈值或换分箱挽救结论。

## 7. 备选方案边界

可以先用少量已审计 group 做两臂 smoke check，只检查输入、NLL、argmax、mask 和 manifest 契约。该结果只能标为工程可行性信号；若使用 `val-dev`，必须明确它参与过 B0 模型选择，不能作为正式 `C/E` 证据。[PR001][PR003][RE447]
