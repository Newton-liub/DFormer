## 1. 一句话目标

本计划原拟以已经冻结的 DFormerv2-S RGB Quick-B0 为基础模型，在 `val-dev` 上回答“人为破坏有效 Depth 后，模型性能是否出现足够大且方向稳定的退化”；只有未来重新启用、A2 得到 `A2-pass` 且用户明确批准，才可能进入 B2 depth-validity gating 的规格、实现和零训练验证。

这是一个小型条件式阶段，不把 B2 短训、完整独立训练、配对 screening（筛选）或 official test 一并展开。

## 2. 关键概念与边界

- **A2**：对冻结 checkpoint 注入预注册的 Depth corruption（深度破坏），测量性能随破坏强度、mask 类型和填充值的变化；A2 不更新模型权重。
- **B2**：显式传递 depth-validity（深度有效性）并调整 depth decay 的 gating（门控）机制；当前尚未实现。
- **B1**：`safe_masked_mean` 数值稳定性修复，固定保留，不作为 A2/B2 的待筛选变量。
- **人工证据与自然证据**：人工 corruption 可以作为 B2 工程开发门槛；自然无效深度分层用于约束结论能否外推到真实缺失机制。自然证据不足不自动否决工程开发，但禁止声称现实部署收益。
- **零训练验证**：使用冻结 checkpoint、不更新权重，验证 B2 机制、兼容性和人工条件下的即时行为；它不等于训练后性能结论。

旧 epoch-10 checkpoint、16 张 official-test 样本的 A2 pilot 只保留为历史依据。它没有绑定当前 RGB B0，也不满足完整 `val-dev`、mask/fill 对照和 official-test 封存边界，不能作为正式 A2 或进入 B2 的依据。

## 3. 已冻结的共同身份

- 基础模型：DFormerv2-S RGB Quick-B0，最终 checkpoint 为 epoch 420 的 `selector-epoch-420.pth`。
- checkpoint SHA-256：`f246a3afc50334c81302b7bfebdadf7cf37d00326bf1c3aa54f6a151754e3a1c`。
- `val-dev`：318 条，split SHA-256 为 `1d0719d8f64f016d48995c25ab66d4004d76b7155d9efeef7cbb7454c0dd0e83`。
- 输入：RGB 与 `rgb-imagenet-rgb-order-v1`；Depth 使用当前全局量化 8-bit 输入契约。
- 指标：恢复到 MUSeg 原始 Label 网格计分。
- official test：继续保持 `sealed_unread`（封存未读）。

A2 必须复用冻结 B0 的 checkpoint、split、输入契约和 evaluator 身份。B2 若进入后续训练，必须从同一官方 pretrained 独立训练，不能从 B0 最终 checkpoint 接着训练后称为公平消融。

## 4. 三个顺序任务

1. **A2 协议与本地准备（原拟议任务）**：冻结 corruption 矩阵、mask 生成、自然分层、聚合和裁决规则；实现不更新权重的 evaluator 支线并完成最小 CPU 定点检查。该任务未执行，不产生研究指标。
2. **正式 A2 与裁决（待单独授权）**：先通过 `q=0` 等价和完整性门禁，再在完整 `val-dev` 上执行冻结矩阵，输出 `A2-pass`、`A2-stop` 或 `A2-inconclusive`。
3. **条件式 B2 与零训练验证（仅 A2-pass + 用户批准）**：冻结 validity、shape 和 GSA（几何自注意力）数学语义，完成实现、金标准、strict checkpoint、forward/backward 和 `B2-zero-train`。B2 短训及更大实验矩阵另立计划。

三个任务严格顺序执行。`A2-stop` 结束本轮 B2；`A2-inconclusive` 保持阻塞，只能在用户批准的新协议中安排最多一次有针对性的补充验证。

## 5. 重新启用前明确不做

- 不根据本规划直接运行完整 `val-dev` A2、GPU、训练、长耗时评估或云任务；
- 不实现或执行 B2，除非已经取得 `A2-pass` 和用户对任务 3 的明确批准；
- 不做 B2 短训、完整独立训练、配对 screening、额外 seed 或组合模块；
- 不读取、解封或以任何方式使用 official test；
- 不把旧 pilot、自然分层相关性或零训练行为写成训练后鲁棒性结论；
- 不移除 B1，也不改写已经完成的 Quick-B0 结果。

## 6. 本阶段到哪里算完成

本小计划的合法终点有三种：

1. `A2-stop`：证据不足以支持 B2，本阶段以 B0-only 收口；
2. `A2-inconclusive`：记录缺失条件和准确恢复点，不自动继续 B2；
3. `A2-pass` 后完成获批的 B2 实现与 `B2-zero-train` 裁决，输出 pass/stop/inconclusive，并把任何训练性验证移交给新的后续计划。

每个任务结束都必须先更新 [`MUSeg-current-status.md`](../../../../main/MUSeg-current-status.md)。实验口径发生处置变化时，同时更新 [`MUSeg-open-decisions.md`](../../../../main/MUSeg-open-decisions.md)。
