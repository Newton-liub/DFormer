## 1. 一句话目标

建立独立的 Multi-Modal Failure Robustness（MMFR，多模态失效鲁棒性）研究族，在 MUSeg 上研究 RGB/Depth 完全缺失、局部缺失、噪声、模糊、量化和几何错位及其混合条件，并用合成失效的已知身份监督一个可学习可靠性估计器；本计划只主张 MUSeg 域内的合成失效开发证据，不把它写成真实矿井传感器可靠性结论。

本计划的失效生成与 A2 训练接入当前采用 v2 身份：corruption basis 为 `MMFR-A1-corruption-basis-v2`，A2 协议为 `MMFR-A2-train-integration-v2`（supersede `MMFR-A2-train-integration-v1`）。全部失效都是 **model-input/representation-level synthetic corruptions**（模型输入/表示层合成损坏），不是 Kinect 真实物理噪声模型。

## 2. 对四个问题的方向级裁决

1. **MUSeg 可以用，但不能单独承担全部结论。** 它有 3,171 对对齐 RGB/Depth、六个矿区和 15 类标注，适合在固定语义域上训练和比较受控失效；公开数据定位是对齐分割数据集，并没有自然传感器失效标签、重复采集、标定漂移真值或故障发生率，因此只能支持合成失效鲁棒性和矿井域开发证据。
2. **模态失效不能等同于 Depth 置零。** 本计划把失效拆成完全缺失、空间不完整、统计噪声、模糊/分辨率损失、量化/截断、RGB–Depth 几何错位和多失效混合。Depth 置零只是“完全或局部缺失”的一个编码。
3. **先从训练分布和可靠性监督下手，不再先改注意力公式。** 2025 年 MMSS 失效基准已明确区分 Entire-Missing、Random-Missing 和 Noisy Modality；M3L 与 RMMSS 等工作把 modality masking、教师监督或跨模态蒸馏作为核心训练机制。信号特征只作为可学习估计器的输入，包括无效值、局部均值/方差、Sobel 梯度、Laplacian、高频残差和跨模态梯度一致性，不把任何单一手工指标当作最终门槛。
4. **可靠性与贡献权重应可学习，但必须受约束。** 合成 corruption 提供像素级连续可靠性目标，网络学习 RGB/Depth 可靠性；四级 adapter 再学习“深度项缩放”和“空间项补偿”，而不是把人工阈值直接当作最终 gate。所有新参数必须在独立训练中从同一官方 pretrained 起步，不能从 Quick-B0 最终 checkpoint 续训后冒充公平消融。

## 3. DVG-B1 负结果带来的架构修正

DVG-B1 已证明“知道真实坏区后把 GSA depth contribution 乘到零”仍会变差。这个结果不等于可靠性学习无效，而是说明以下跳跃不成立：

- corruption mask 不等于模型需要的贡献权重——“知道哪里坏”不等于“知道模型该采取什么动作”；
- 空间先验回退路径从未在此类失效上训练；
- 同一个可靠性值在不同 stage、类别和失效类型下未必对应同一个融合动作；
- DFormerv2 是 **RGB-primary semantic path + Depth geometry-prior path 的非对称架构**：语义编码以 RGB 为主，Depth 作为 geometry prior 进入 GSA，而不是与 RGB 对称的显式语义编码分支，因此仅调 GSA 不能解决 RGB 完全失效。

因此首选设计是先学习可靠性，再由小型 adapter 学习融合动作；如果目标包含 RGB 完全失效，后续必须引入 Depth 语义特征路径或共享/双流编码，不能声称现有非对称 DFormerv2 仅靠门控即可完成。该需求与 B1 严格分离，作为 B2 的三个预研选项处理（见第 6、7 节）。

## 4. 数学与信号设计

对每个模态 $m$ 和像素 $p$，合成器记录各失效基函数的局部负担 $b_{m,k}(p) \ge 0$。组合可靠性采用乘法语义：

$$
R_m^*(p)=\exp\left(-\sum_k b_{m,k}(p)\right).
$$

这使多种轻度失效可以累积为较低可靠性，又避免用单一二值 mask 覆盖噪声、模糊和错位。v2 的 severity 只编码一次：severity 只选择 corruption 参数，graded kinds（`gaussian_noise`、`blur`、`quantization`）的连续 burden 就是 realized normalized damage $b=\operatorname{clip}(\max_{\mathrm{ch}}|\Delta_{\mathrm{ch}}|/(255\cdot \mathrm{DAMAGE\_REFERENCE}),0,1)$，`DAMAGE_REFERENCE=0.25`，不再二次乘 severity。`blur` 与 `misalignment` 的 severity 是相对尺度的比例，而不是绝对像素量：`blur` 的 $\sigma=\text{severity}\times \mathrm{BLUR\_SIGMA\_FRACTION}\times \min(H,W)$（`BLUR_SIGMA_FRACTION=1/80`，等价于 v1 在冻结 `480` 像素 crop 上的 `6.0` px 上限）；`misalignment` 每轴最大位移为 $\text{severity}\times \mathrm{MISALIGN\_MAX\_SHIFT\_FRACTION}$ 乘对应轴长度（`MISALIGN_MAX_SHIFT_FRACTION=1/30`），有效区 burden 为实际位移除以该尺度允许的最大位移，越界像素取 `MISSING_BURDEN=1.0e4`。

可靠性头输出两通道 logits，但 A2 v2 只监督 Depth 通道，辅助损失使用连续二元交叉熵或等价稳定实现：

$$
\mathcal L_{rel}=\operatorname{BCE}\!\left(\hat R_d,\;R_D^{sup}\right),
$$

监督目标为 $R_D^{sup}(p)=V_D^{pre}(p)\cdot R_D^{syn}(p)$，其中 $V_D^{pre}=$ `raw_depth_pre > 0 AND valid_mask` 是 corruption 前的真实输入有效性，$R_D^{syn}$ 是 A1 v2 的合成 Depth reliability surrogate。RGB 通道保留为两通道接口的 all-ones scaffold：不计入 loss、不报告 calibration 指标、不得称为已训练的 RGB reliability estimator；B1-v1 同样只能消费 Depth reliability。

未来训练目标候选为：

$$
\mathcal L=\mathcal L_{seg}^{corrupt}+\lambda_{rel}\mathcal L_{rel}+\lambda_{cons}\mathcal L_{clean\leftrightarrow corrupt}.
$$

其中一致性项只在 clean teacher 高置信且标签有效的位置使用；$\lambda_{rel}$、$\lambda_{cons}$ 必须在训练前冻结，不能根据模型结果反复调整。

四级几何 adapter 不直接使用 $R_d$ 作为硬门槛，而学习两个有界或正值缩放：

$$
G_l=w_s\,a_l(\hat R_d)G_s+w_d\,b_l(\hat R_d)G_d.
$$

初始化要求 $a_l=b_l=1$，保证新 adapter 在未训练时是原模型语义的 no-op。RGB 完全失效不在该几何 adapter 的能力声明内。B1 的冻结设计原则见第 7 节。

## 5. 失效基函数与 curriculum

首轮基函数固定为：

- `entire_missing`：整模态缺失，burden 为 `MISSING_BURDEN=1.0e4`，仅重度阶段出现且 severity 固定 `1.0`；
- `spatial_dropout`：局部块状缺失，被丢弃像素取 `MISSING_BURDEN`，extent 随 severity 单调；
- `gaussian_noise`：连续加性噪声，$\sigma=\text{severity}\times 48$ 个 uint8 单位；
- `blur`：Gaussian 模糊，v2 的 severity 为相对尺度量 $\sigma=\text{severity}\times (1/80)\times\min(H,W)$，不再是绝对像素数；
- `quantization`：Depth 位深/台阶损失，$\text{levels}=\operatorname{clip}(\operatorname{round}(256(1-\text{severity})),2,256)$；
- `misalignment`：Depth 相对 RGB 的小幅平移，v2 每轴最大位移为 $\text{severity}\times (1/30)$ 乘对应轴长度，越界区域显式无效并取 `MISSING_BURDEN`；
- `mixed`：按固定随机种子顺序组合两个或以上基函数。

v2 中 graded kinds 的连续 burden 统一等于 realized normalized damage，severity 只编码一次。这些基函数生成的全部失效都是 model-input/representation-level synthetic corruptions，不是真实传感器物理噪声模型，也不提供自然故障真值。

curriculum 只控制允许的最大 severity 和同一样本最大组合数：前期单一轻度，中期单一中度与少量双失效，后期包含重度和混合。采样器必须使用调用方传入的随机数生成器，不读写进程级全局随机状态。

## 6. 数据与实验身份

- **数据：** 当前开发职责保持 `train-dev=1277`、`val-dev=318`；official test 保持 `sealed_unread`。
- **训练起点：** 后续所有 clean control 与 robust model 都从同一官方 `DFormerv2_Small_pretrained.pth` 独立训练。
- **禁止续训：** 不从 `selector-epoch-420.pth` 续训后与原 Quick-B0 直接宣称公平。
- **模型边界：** `MMFR-B1` 只研究 Depth reliability 对 geometry prior 的可学习适配；覆盖 RGB 完全失效需要独立 `MMFR-B2`。B1 的最小 baseline 是 `B1a-global-reliability-baseline`（`mean/std reliability -> global scale`），不得作为 B1 最终默认方案。B2 与 B1 严格分离，扩写为三个预研选项：`B2a explicit Depth semantic fallback`（默认首先研究，对当前 DFormerv2 改动最可控）、`B2b feature reconstruction/compensation`（参考 KSTrack 的 prototype + feature reconstruction）、`B2c modality-agnostic representation/pretraining`（参考 Yu 的 modality-asymmetric reconstruction）。CMNeXt 不能当作解决 RGB-complete-missing 的直接模板，因为它本身建立在“RGB representation is essential”的 primary RGB branch 假设上。
- **冻结常量与曲线口径：** A2 v2 的 corruption 冻结为 `p_clean=0.25` / `p_corrupt=0.75`、三阶段 curriculum、`max_specs=2`、`lambda_rel=0.1`、500 epoch；报告口径为六单失效宏平均主 score、clean mIoU 下降不超过 `0.50` 个百分点、paired location-group bootstrap。severity 只编码一次，`blur`/`misalignment` 使用相对尺度。
- **评价：** checkpoint selector、十视图 evaluator、六个单失效、三个混合失效、196 个 location-group paired bootstrap 和成功门槛已冻结于 [`03-MMFR-A2训练接入与公平对照协议.md`](03-MMFR-A2训练接入与公平对照协议.md)；当前未实现 evaluator，也未运行评价。

## 8. 文献证据边界

- MUSeg 数据集：Scientific Data 2025，3,171 对精确对齐 RGB/Depth、六矿区、15 类；这支持域内分割研究，不提供自然失效真值。
- *Benchmarking Multi-modal Semantic Segmentation under Sensor Failures*（CVPRW 2025）：把失效分为 EMM、RMM、NM，并显示常规模型在失效下显著退化。
- M3L（WACV 2024）：完整模态 teacher 监督随机遮蔽模态的 student，说明训练式 masked-modality learning 比只在测试时置零更合理。
- RMMSS（arXiv 2025）：用 modality masking、自蒸馏、跨模态 prototype distillation 和 feature selection 同时追求缺失模态鲁棒性与 clean 性能。
- Deep evidential fusion（Information Fusion 2024）：通过学习 reliability coefficient 对来源证据做 contextual discounting，支持“可靠性应学习而非完全手定”的方向，但其医疗决策级融合不能直接当作 DFormerv2 的公式依据。
- 2025 年 wavelet multimodal frequency fusion 等工作支持引入频域信息；本计划只把固定信号算子作为估计器输入，不声称 wavelet 本身即可证明可靠性。
- KSTrack：在 tracking 场景以约 50% modal-incomplete 设置和 prototype + feature reconstruction 处理模态不完整；它可作为 B2b 的直接参考，但其 50% 比例属于 tracking 场景，不能据此推出 MUSeg 的最优 corruption ratio。
- Yu 等的 modality-asymmetric reconstruction 工作：以模态非对称重建处理模态缺失，可作为 B2c（modality-agnostic representation/pretraining）的参考。
- CMNeXt：不能当作解决 RGB-complete-missing 的直接模板，因为它本身建立在“RGB representation is essential”的 primary RGB branch 假设上。

## 9. 禁止事项

当前不运行正式训练、完整评价、云资源或 official test；已完成的本地 GPU 单步 preflight 只证明训练链能够更新一次。本机后续只做推理、想法初步验证和小规模 preflight，正式训练固定为云端单卡且默认选择 RTX 4090。不读取 Quick-B0 checkpoint 做续训；不修改 DVG-B1 历史 protocol；不把代码脚手架或单步 preflight 写成模型已有效；不在结果后改变 corruption 定义、severity、成功门槛或 split。

v2 `gradient_path_isolation` 门禁已于 2026-09-15 在本地 GPU 上执行并通过（见第 7 节），“通过之前禁止启动正式 A2 v2 训练”这一前置条件已经满足，因此该检查不再构成阻塞；正式训练仍未授权，启动正式 A2 v2 训练仍须用户单独授权。不因新论文采用 50% missing 等设置而照抄：KSTrack 的 50% modal-incomplete 属 tracking 场景，不能推出 MUSeg 最优 corruption ratio；若未来发现 exposure 不合适，只能新开 protocol，不能在当前冻结身份内调整 `p_clean`/`p_corrupt`、curriculum 或 `max_specs`。
