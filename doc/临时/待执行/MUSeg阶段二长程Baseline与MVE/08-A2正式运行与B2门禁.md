# 08：A2 正式运行与 B2 触发门禁计划

> 任务类型：冻结矩阵的 GPU 推理、统计和研究决策。
>
> 模型要求：Terra 可机械执行矩阵和汇总；**A2-G/N-G 解释和 B2 触发只能由 Sol 签署并由用户确认。**

## 1. 前置条件

- 07 的工具提交已合入，测试和 q=0 等价通过。
- 05 指定的三个 development checkpoints、val-dev 和所有 SHA 匹配。
- A2 protocol manifest 已由 Sol 冻结。
- 4090 环境 preflight 通过，输出目录全新。

## 2. 运行顺序

1. 对三个 model seeds 逐个执行，不在单卡并发。
2. 每个 model seed 内按 manifest 固定顺序运行 mask seed、mask type、fill type、q。
3. q=0 先跑并和 baseline evaluator 再做一次等价检查；失败时停止全部。
4. 每个条件记录开始/结束、退出码、样本数、预测数和日志。
5. 条件失败不自动跳过或补跑到同一目录；查因后使用新 run ID，旧结果保留并标记 invalid。
6. 所有 GPU 前向完成后，使用独立 evaluator 从保存预测重算统计。

## 3. 完整性验收

- 实际条件集合与 manifest 精确一致。
- 每个条件样本数、CSV 行数、预测文件数闭合。
- checkpoint/split/tool commit SHA 未变化。
- loss 不适用时不伪造训练指标；推理无 NaN/Inf logits 或 metrics。
- q 增加时实际注入像素数正确；zero/median 使用同 mask。
- 三 model seeds 和至少两 mask seeds 全部完成。

## 4. 预注册 A2 判据

正式判据沿用并强化历史设计：

### A2-G（允许进入 B2 规格设计）

核心条件至少同时满足：

1. `q=0.3 block zero` 相对 q=0 的平均前景 mIoU 下降至少 2.0 个百分点；
2. 至少 75% 图像的同图配对差为负；
3. q=0.1→0.3→0.5 的平均性能总体不升，具有剂量趋势；
4. model seeds 与 mask seeds 的方向一致，不由单个 seed 驱动；
5. zero 退化相对 median 负对照有足够差异，支持“无效 0 数值语义”而不只是信息删除。

第 5 项的数值门槛必须由 Sol 在运行前写入 protocol，不得看结果后补定。

### A2-N-G（停止 B2）

满足任一强失败条件即停止：

- q=0.5 下降仍不足 0.5 个百分点；
- 不同 q 无一致趋势；
- 效应只存在于单个 model/mask seed；
- zero 与 median 没有支持预设机制的差异；
- 自然无效深度分层不支持现实场景相关性。

### 中间态

结果接近门槛、区间跨门槛或只在人工 block 下成功时，不自动进入 B2。Sol 可提出一次预先约束的补充实验，但必须新建 protocol version，不能无限追加条件。

## 5. 结果解释边界

- 只在人工 corruption 成功：只能说明鲁棒性风险，不能声称自然 `Depth=0` 是主要瓶颈。
- 自然高无效率组也退化且 seed 一致：可增强现实相关性证据。
- paired effect 比绝对 mIoU 更重要，但 baseline 本身必须成熟。
- official baseline test 结果不用于修改 A2 判据。
- 历史 epoch-10/16 图结果与正式结果并列作为 pilot，不合并统计。

## 6. 人工门禁 G

Sol 向用户报告：

- 每个 model/mask seed 的完整矩阵；
- 配对效应、区间、负差比例、剂量趋势；
- block/random、zero/median、自然无效率分层；
- 与历史 pilot 的一致/冲突；
- 明确判定 A2-G、A2-N-G 或中间态及逐项依据。

只有“A2-G + 用户明确批准”才能创建/执行 09。Terra 无权把“有一点下降”解释为通过。

## 7. 产物与 Git

- 预测、mask、日志和矩阵结果保存在实验输出盘，不进 Git。
- 可提交小型最终报告和 evidence index，但不得包含大型数据或敏感路径/凭据。
- 无代码修改时不创建代码提交。
- 运行中发现工具问题，返回 07 修复并使受影响矩阵作废。

## 8. 完成标准

- 正式 A2 矩阵和独立统计完整可重算。
- Sol 给出预注册判定并经用户确认。
- A2-N-G：在总索引中将 09–11 标为取消，项目回到 baseline/其他瓶颈研究。
- A2-G：才允许进入 09；此时仍未实现 B2。
