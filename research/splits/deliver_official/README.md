# DeLiVER official split manifests

Generated by `python -m research.deliver prepare --root <DELIVER> --split-dir research/splits/deliver_official`
on 2026-10-10 from the local `D:\0Project\dataset\DELIVER` copy.

Each line is a path **relative to `<DELIVER>/img/`** with forward slashes:

```
<weather>/<split>/<scene>/<name>_rgb_front.png
```

`research/deliver.py` derives the other modalities from the same path: the
modality root is swapped (`img` -> `depth` / `semantic`) and the file-name token
`_rgb` becomes `_depth` / `_semantic`. This mirrors the official loader
(`semseg/datasets/deliver.py`) except that the official "depth" modality is
`hha/`, while the approved protocol here reads the raw `depth/` directory.
