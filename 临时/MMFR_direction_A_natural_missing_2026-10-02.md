# 方案 A：真实深度缺失形态覆盖与低成本训练增强

> 版本：v1.0｜日期：2026-10-02  
> 定位：优先候选；问题驱动的方法与实证研究。  
> 状态：方向方案已形成，效果与新颖性均未被证明；尚未实现、训练或进行新评价。  
> 配套方案：`MMFR_direction_B_inference_protocol_2026-10-02.md`。两份文件可独立阅读，不要求同时开展两条实验线。  
> 核心原则：先确定可被推翻的论文主张，再做最多两轮方向筛选。首轮没有明显收益就停止，不进入补模块循环。

## 0. 一页决策摘要

**建议优先验证：在相同训练机会、相近新增缺失量下，用训练集真实空洞形态替代规则网格删除，能否改善自然缺失较重图像上的语义分割。**

不改 DFormerv2-S 主干，不增加推理模块，不恢复深度，不学习可靠性门控。首轮允许对现有分割器全参数微调，而不是继续限定为“冻结底座，只训练一个小残差”。

本轮对上一版设想作三项明确修订：

1. **不再把现有 `spatial_dropout` 写成独立像素丢弃。**本地实现是随机网格块删除；新方法必须与这个更接近的对照比较。[E0 §4]
2. **取消首轮必做的 context-matched（场景条件匹配）分支。**亮度与缺失率仅呈弱正相关，且存在矿井组成与预过滤偏差；目前没有证据支持“按亮度匹配就是正确的失效机制”。不凭空选择条件变量。[E0 §3.2]
3. **加入等预算自然输入续训对照。**现有训练图本来就有真实空洞，不能声称原模型“从未见过真实缺失”；也不能把更多训练带来的提升记给新增强。[E0 §§2–3]

拟用工作题目：**《缺失量之外：面向自然深度空洞的 RGB-D 语义分割训练覆盖》**。题目中的“覆盖”指训练样本分布，不意味着已经建立了真实传感器物理模型。

| 必答问题 | 本方案的回答 |
| --- | --- |
| 实际问题 | 规则人工删除与自然空洞在空间形态上不同；这种差异是否造成可改善的任务缺口，仍待验证。 |
| 已有工作 | 模态丢弃、恢复、蒸馏、可靠性融合和局部损坏评价都有先例；真实形状重放本身不自动构成创新。 |
| 失败启示 | 旧残差、恢复和门控没有给出稳定收益，不应继续假定“换一个模块就能解决”。 |
| 潜在新增 | 在控制新增有效缺失量、训练预算和评价口径后，建立形态影响的任务证据，并给出无推理开销的训练修正。 |
| 最小验证 | 第一轮三组同底座训练；通过后第二轮固定方法复现并迁移 NYUv2。 |
| 停止原则 | 自然数据无明显收益、只赢自造损坏、或不能胜过简单对照，立即淘汰本候选。 |
| 最终数据与对照 | MUSeg + NYUv2 原始未补洞深度；DFormerv2-S、CMX-B2、GeminiFusion-B2、独立 RGB-only，以及至少一个缺失鲁棒训练方法。 |

**这是“值得花一轮验证”的优先判断，不是发表保证。**以快速成文为目标，先投入这一条；方案 B 的统一单视图入口可作为共用基础，但不必先完成整篇评测研究。

### 1.3 数据集选择偏差不能省略

MUSeg 论文第 5 页说明：保留 RGB 好而 Depth 差、RGB 差而 Depth 好的互补样本，同时过滤部分“有效深度不足 40% 且 RGB 均值低于 40”的双低质量图。第 6 页还说明低光图像会用深度辅助标注。因此，本方案研究的是**已发布数据中的部分自然缺失**，不是所有矿下极端失效，也不预设剩余 RGB 足够恢复所有标签。[RE326]

E0 没有读取标签；全图缺失率也包括未标注区域。后续评价必须保留固定的有效标签规则，并报告高缺失子集的类别/采集组支持，不能把“缺失率高”直接写成“语义信息损坏重”。

## 4. 论文主张与可证伪假设

### 4.1 唯一主问题

> 在同一 RGB-D 分割器、相同更新预算和相近新增有效缺失量下，训练时增加真实空洞形态，是否比规则网格删除更能改善未额外损坏的自然缺失样本？

“真实”仅指掩码来源于实际采集的训练图。把它移动到另一张图后，它仍是**真实形态来源的人工增强**，不是那张目标图真实发生的传感器故障。

### 4.2 三个必须同时回答的假设

- **H1：任务价值。**增强的收益出现在自然输入，而不只出现在自己的合成测试中。
- **H2：形态价值。**收益超过等预算自然输入续训和有效删除量匹配的网格增强；否则不能归因于真实空洞形态。
- **H3：外部有效性。**固定训练规则后，在第二数据集及另一编码结构上仍有同方向证据；否则只能定位为当前模型/数据集的特定现象。

当前统计只为 H1/H2 提供动机，三者均未成立。

### 4.3 明确不主张什么

不主张已发现真实失效成因，不主张解决 RGB 与 Depth 同时无信息的问题，不主张恢复毫米真深度，不主张泛化到未出现过的所有传感器，不主张首次提出增强、模态丢弃或可靠性学习。

## 5. 最小方法：训练集空洞形态重放，不增加网络

### 5.1 首版固定取舍

采用 **train-only real-mask replay（仅用训练集的真实缺失形态重放）**。不做亮度匹配、矿井条件路由或语义原型检索；这些都不是首轮失败后的备选修补。

源掩码定义为原图 `Depth16 == 0`。E0 已确认这批 dev 图中它与 `Depth8 == 0` 一致；只把该结论用于已核验数据，不推广到新数据集。[E0 §§2–3]

按“先抽源采集组，再抽该组一张图”获得源掩码，排除目标图所在组，避免同位置多视图重复充当很多独立来源。源、目标都来自 train-dev。此采样选择是控制组内重复的设计，不是对矿井失效率的估计。

### 5.2 插入位置与零值语义

优先复用 `utils/mmfr_training.py::build_mmfr_training_batch_v3` 附近的输入增强入口，采用独立新配置，不覆盖旧 v3 合同。

源二值掩码用最近邻变换到训练网格，所需 mirror/scale/crop/pad 信息通过最小的数据预处理接口传递。目标 Depth 仍沿现有数值预处理路径；不顺便改插值器或把全部原洞重新阈值化。新增网格掩码与真实掩码在**同一插入点**生效。

这一取舍区分两个对象：源形状来自原始无观测区域；实际新增失效量在当前训练输入的有效支持上计算。线性缩放后的目标零值支持可能与原始二值支持不同，这是已知限制，不写成已解决的物理仿真。[E0 §§5、9]

写零应在合法 uint8 深度空间完成，再按现有方式归一化，并同步 validity state。当前 raw 0 归一化后约为 −1.7142857；normalized 0 是另一种值，padding 也不能当作自然空洞。[E0 §5]

### 5.3 必须匹配的是有效删除量

令 $S$ 为不含 padding 的空间支持，$V$ 为额外增强前当前输入中有深度观测的位置，$M$ 为拟删除掩码。

$$
q=1-\frac{|V|}{|S|},\qquad
r_{\mathrm{add}}=\frac{|M\cap V|}{|V|},\qquad
q'=q+(1-q)r_{\mathrm{add}}.
$$

$q$ 是原有缺失比例，$r_{\mathrm{add}}$ 是原本有效点中新删除的比例，$q'$ 是最后缺失比例。$|V|=0$ 时不定义删除率，直接保留该样本并记录跳过；不为它补深度。

例如原来缺失 30%，再删剩余有效点的 50%，最终缺失是 65%，而不是 80%。这只是上述定义的算术示例，不是 MUSeg 实测值。

首版建议保留 25% 未额外增强的样本，其余槽位尝试重放；有效新增删除率限制在 10%–50%。这个区间是控制探索成本的初始设定，不声称最优。训练前固定，不根据 val 修改。

真实形态组先生成候选掩码并记录实际 $r_{\mathrm{add}}$；网格对照在相同样本槽位按随机块顺序选取接近该删除量的掩码。建议绝对误差不超过 0.02。不得为了精确匹配而逐像素打碎真实掩码。可设置有限候选尝试，例如最多 8 次；无法匹配时两组共同跳过该槽位，报告实际增强比例和删除量分布。

**若大量槽位无法匹配，就先报告这个训练设计不可执行；不要扩建复杂掩码优化器。**匹配容差、尝试次数属于新实验实现约定，不是新的论文模块。

## 6. 第一轮：三组训练，一次统一评价，决定是否继续

### 6.1 三组实验，不再沿用旧 A/B/C 的场景匹配设计

| 组别 | 训练变化 | 用途 |
| --- | --- | --- |
| A-Natural | 原始自然 RGB-D 输入，普通空间/颜色增强，无新增深度删除 | 排除仅靠更多训练获得收益 |
| A-Grid | 新增规则网格块删除；与 A-Replay 匹配样本槽位及有效删除量 | 排除“损坏更重/更轻”以及普通块增强已经足够 |
| A-Replay | 用不同训练采集组的自然空洞形态新增删除 | 待验证的方法 |

另将**未继续训练的 C0**用同一新评价入口计分，作为历史底座锚点，不增加第四个训练 run。

三组初始权重、训练样本顺序、普通增强、损失、可训练参数范围和更新预算相同。训练模型均为原 DFormerv2-S + 原解码器，不含 F-lite、R-OE 或 A-v1。

首轮不叠加噪声、错位、恢复和蒸馏。A-Grid 是有效删除量匹配的对照，不冒充完全复现旧 v3 的混合故障课程；完整 v3 增强属于最终论文须补的强训练对照。

### 6.2 建议训练预算

优先从恢复的 C0 fixed-final 初始化，三组**同范围全参数微调**。优化器重新建立，不继续沿用训练终点接近零的学习率；初始学习率建议取历史 C0 配置正常起始学习率的 0.1，其他基本优化设置沿用成熟配置。

首轮上限建议每组 **2560 次成功更新**，有效 batch 10 时约相当于当前 train-dev 的 20 个 epoch；保存并比较 fixed-final，不利用 val 挑多个候选 epoch。先根据已恢复环境给出时间估计，再执行获批预算。

这是项目资源筛选预算，不代表方法一定充分收敛。预算内无明显收益就停止此候选，不通过延长训练、换主干或加模块“救活”。OOM、数据读错、更新未执行等工程失败不作效果结论，但也不得成为无期限补测理由。

### 6.3 统一评价入口

第一轮只用同一设备、同一软件环境、FP32/TF32-off 的单视图评价：原图网格、whole-image、统一右下 padding 到 32 倍数，输出裁 pad 后回原标签网格。不与旧 Quick-Val 的无 pad 数字直接比较。

此入口可从现有 Main-Val view builder 的原尺度 original view 提取，不重写整套 evaluator。候选间复用相同输入及随机起点；HAM/NMF 的随机性不能仅靠 `eval()` 消除。[E0 §§6–7]

评价三种输入，均使用全部 318 条 val-dev：

1. **原始输入**：主证据，不增加人工故障。
2. **单个连续矩形新增删除**：只作为本轮未用于训练的生成器测试；在原有效支持上以 50% 新增删除为目标，记录实际比例，不以标签定位矩形。
3. **entire-missing**：仅作失效退路检查，不把它描述为 dev 中自然发生的全空情况。

矩形压力测试不是新的真实数据，也不是绝对未见的几何形状；不能单靠它证明现实泛化。首轮不另跑十条件十视图。

### 6.4 主指标与分层

原始输入按 E0 已有 train 阈值固定分层：低缺失 $q\le0.1076104892$；高缺失 $q>0.4944140560$。对应现有 val-dev 为低 80 图、高 64 图；本方案沿用，不根据分数另挑子集。[E0 §3.3]

主指标为**原始输入高缺失子集 mIoU**，同时报告原始全体、原始低缺失子集及两种压力条件。对每个集合先累计 confusion matrix（类别混淆计数）再算 mIoU，不能直接平均逐图 mIoU。

类别映射、ignore index 与当前任务一致。子集中无真实标签支持的类别如何处理，在读取分数前统一确定，所有候选使用相同类别集合；不得为了涨分删除困难类别。记录子集包含的采集组数、各类真实像素支持，以及缺失落在有效标注区域的比例，用来限制解释，不改变已定分层。

只保存逐图/逐组计分所需的小型统计，不默认导出所有 logits 或大规模可视化。按组检查收益是否由少数重复场景支撑；不把同组图片当独立证据。

### 6.5 第一轮停止线

以下为**拟议投入门槛**，不是领域通用标准、统计显著性声明或最终论文标准。必须在运行前接受或一次性修订，看到结果后不下调。

| 项目 | 继续要求 |
| --- | --- |
| 自然高缺失子集 | A-Replay 比 C0、A-Natural、A-Grid 中该指标最强者至少高 **1.0 pp** |
| 原始全体与低缺失子集 | 各自不比上述对照最强者下降超过 **0.3 pp** |
| 未用于训练的矩形删除 | 比 A-Natural/A-Grid 的较强者至少高 **0.5 pp** |
| entire-missing | 相对 A-Grid 不下降超过 **0.5 pp**；不要求此条件大涨 |
| 证据可解释性 | 两种删除方式预算确实接近；收益不能仅来自无效类别口径、少数重复采集组或输入处理差异 |

**任一关键要求不满足：STOP。**没有“先增加 context matching 看看”的下一步。微小正差、自然数据没改善、仅在自造退化获胜，均不进入第二轮。

如果实际输入/标签错误使本轮无效，状态写 BLOCKED，区分工程失败与科学假设未获支持；不能把无效 run 的分数拿来选方法。

## 7. 第二轮与最终论文：固定方法后验证，不继续改结构

### 7.1 第二轮方向确认

只有第一轮过线才安排：

- 在 MUSeg 上对 A-Replay 与第一轮最强训练对照做一次新的配对训练种子复现；算法、超参数和评价口径不变。
- 在 NYUv2 上建立原始未补洞深度输入，运行固定的自然输入/网格/重放对照；掩码只来自 NYUv2 的训练部分，不直接混入 MUSeg 掩码。

建议继续要求：MUSeg 新种子的自然高缺失收益仍至少 +0.5 pp，原始全体损失不超过 0.3 pp；NYUv2 原始高缺失子集对最强简单对照至少 +0.5 pp，并保持同样全体保护线。高缺失阈值重新由 NYUv2 的训练数据计算，不照搬 MUSeg 数值。

若 MUSeg 不复现或 NYUv2 完全不支持，结束这个具体候选。不得把“改另一数据集”“换更大编码器”当作不计轮次的修补。

### 7.2 通过后需补齐的固定论文证据

两轮是**方向筛选**，不是承诺两轮就完成所有论文实验。通过后按一次确定的矩阵补齐正式比较，而不是重新搜索结构：

| 证据 | 最低用途 |
| --- | --- |
| 两数据集的原始输入、预定义缺失分层与少量固定压力条件 | 证明不是只对本人的生成器有效 |
| A-Natural / A-Grid / A-Replay，以及同预算现有 v3 混合增强 | 证明收益超过续训、规则删除和已有成熟增强 |
| 主干外迁移：至少 CMX-B2 上的最强简单对照与 Replay | 支持训练策略不只适用于 DFormerv2 几何先验 |
| 独立训练的 RGB-only；Depth 置零行为单独列名 | 排除仅靠少用 Depth 得到“假鲁棒”的解释 |
| 关键方法与对照共 3 个训练种子；按采集组计算配对区间 | 区分平均收益、训练波动与重复场景影响 |
| 参数量、实际推理延迟、训练额外耗时 | 验证无新增推理模块，不把“零新增参数”写成未经测速的速度结论 |

单视图作为预先确定的主结果。多视图可作补充，但不依赖多视图翻转才能确认贡献；若最终部署主张只适用于单视图，应明确范围。

### 7.3 论文叙事与图表骨架

论文应讲：**已有自然缺失事实 → 同等删除量下的形态问题 → 简单训练修正 → 自然数据与外部数据验证。**不能讲“模块很复杂，因此应该有效”。

保留四项核心展示即可：自然/网格/重放掩码及预算示例；三组训练对照；MUSeg + NYUv2 的原始/高缺失结果；模型外迁移及推理成本。只有真实得到结果后才填写摘要的提升数字。

若最终只有自然输入总体小幅提高、无法区分形态作用，应降低为数据增强工程经验，不强写高强度算法创新。

## 8. 第二数据集与 baseline 的明确选择

### 8.1 第二数据集：NYUv2，不先换掉 MUSeg

NYUv2 官方标注包约 2.8 GB，已包含 `rawDepths`（投影到 RGB 平面、尚未补洞）及 `depths`（补洞后），两者单位均为米。无需为了本方案默认下载约 428 GB 的完整原始录像。[W-NYU]

E0 显示本地数据尚未取得，现有 loader 的 `IMREAD_GRAYSCALE` 和“raw”注释不能证明保留原始深度。因此应读取官方实际字段，确认单位、无效值和固定映射后再构造输入，不能把 MUSeg 的 uint16 毫米假设直接移植过来。[E0 §9；W-NYU]

主实验证据使用 rawDepths。补洞版只可作单独注明的参考，不当作洞内真实测量真值。方法在两个数据集分别训练和评价；“跨数据集有效”不是同一模型零样本跨域成功。

### 8.2 对照清单

| 对照 | 论文中的角色 | 本地准备状态/限制 |
| --- | --- | --- |
| DFormerv2-S / 恢复后的 C0 | 主底座、三组训练消融 | 有代码/配置与远端权重记录；本地可用文件尚待恢复 |
| CMX-B2 | 不同 RGB-X 融合结构；优先做外迁移 | E0 未确认主工程中完整代码、MUSeg 配置和权重组合 |
| GeminiFusion-B2 | 另一种融合设计的系统比较 | 同样不是现成 MUSeg 推理资产 |
| 独立 RGB-only（建议 SegFormer-B2） | 检查是否真正利用深度 | 需要正常训练，不能用双模态模型 Depth=0 冒充 |
| ConD | 至少一个专门处理缺失模态的外部训练方法 | 已有 `RGBD-MMCD` 代码记录，无就绪 MUSeg 权重；用其支持底座，移植则标注移植版 |
| GeomPrompt-Recovery | 最近的任务驱动输入修正近邻，优先补充 | 截至 E0 与本次官方页面检查未确认完整官方源码；不能设为首轮硬依赖，也不能用简化残差冒充复现 |

来源：[E0 §§8、10]。CMNeXt、DFormer++、OmniSegmentor 不作为首轮必做项目。RobustSeg 可在 ConD 确实无法忠实实现时由上级明确替换，不同时默认复制两套复杂训练。

不同方法的 raw/8-bit/HHA 表示必须披露。核心消融统一输入处理；跨模型若使用 HHA，须说明它如何从同一份退化观测生成，不能偷偷使用未受损深度构造的辅助输入。修改了官方预处理就标为适配版，不能与论文原表格数字混排成同条件复现。

### 8.3 划分与 test 使用

MUSeg 当前 train-dev/val-dev 沿用；高缺失规则和掩码库只由 train-dev 决定。val-dev 已多次用于研发，应明确是开发证据，不当作独立最终检验。

最终方法固定后，再决定是否合并官方训练集的开发部分统一重训；方法和对照须使用相同训练数据。MUSeg official test 在最终评价前保持封存。

NYUv2 官方训练/测试划分采用标准版本，40 类映射需明示；开发子集只从官方训练部分按场景划出。用过这些开发图训练的公开 checkpoint，不能直接当作“没见过开发集”的独立初始化。不得为了快速验证而把 test 改名为 val。
