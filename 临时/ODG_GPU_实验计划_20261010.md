## 2. 执行顺序

### A. 最小 GPU 检查

1. 从 `MICRO_BATCH=2 ACCUM_STEPS=8` 开始，有效 batch 为 16。若显存余量明显充足，最多追加一次 `4×4` 短检查；两组最终使用相同组合，不做全面 batch 搜索。
2. 复用 `bash research/run_odg_gpu.sh smoke`，最终组合下 original、ODG 各运行 200 次 optimizer 尝试。
3. 确认 loss 有限、AMP 初期调整后稳定、存在实际成功更新、编码器/几何权重/分割头更新，无显存溢出；记录峰值显存和稳定吞吐。
4. 根据稳定段吞吐估算两组 30/100 epoch 时间和费用。检查快照不续为正式训练。

### B. 两组各到 30 epoch

- 串行执行 `bash research/run_odg_gpu.sh baseline`、`bash research/run_odg_gpu.sh odg`。
- 两组从相同官方 encoder pretrained、新分割头、新 optimizer/scaler 开始；seed `12345`，4757/528 train-dev/dev 划分，480×480，有效 batch16，相同增强、AMP 和优化配置。
- AdamW：lr `8e-5`、weight decay `0.01`、betas `0.9/0.999`；总日程始终为 300 epoch，warmup10、poly0.9。30/100 epoch 只是暂停节点。
- 每10 epoch 在 dev 上单尺度、无 flip 验证；比较 loss、平均交并比（mIoU）、逐类 IoU 和已有少量预测。首个正式 epoch 耗时修正估算。

### C. 条件满足后，两组续至 100 epoch

- 各自使用原实验 `last.pth`，经 `GEOMETRY_MODE=original` 或 `GEOMETRY_MODE=odg` 配合 `bash research/run_odg_gpu.sh resume <对应last.pth>` 恢复。
- 保留 optimizer/scaler/随机状态和原学习率位置，不重新 warmup；实际恢复后的首次更新同时确认设备恢复正常。
- 100 epoch 比较同节点指标与最近多个验证点趋势。复用现有评价入口增加一次两组相同 seed、25% 人工连通孔洞的 dev 对照，检查观测缺失方面的预期收益；不新增训练、损坏增强或评价模块，不称为天然缺失。
- 本轮不读取官方 test 来调参。

启动命令的环境前置沿用 `doc/guides/odg.md`；仅在取得授权、关机保险回读成功后设置授权标记。长任务复用 `screen`，日志复用 SwanLab；在线日志失败保留 CSV，不长期阻塞训练。

## 3. 时间、费用与关机

尚无 SUN GPU 吞吐实测。以下仅为预算情景：假设两组各1–3秒/有效 batch 更新，每 epoch298次更新，另留约20%给验证和保存；暂按已有4090规格报价 ¥1.95/小时计算，执行前回查实际价格。存储与无卡回收另计。

- GPU 检查：预留0.5–1.5小时。
- 检查加两组各30 epoch：约6.5–20 GPU小时，¥13–40。
- 累计两组各100 epoch：约20–62 GPU小时，¥40–121；包含已完成的30 epoch，不重复计费。
- 建议首阶段上限：**¥40且最多20 GPU小时**；条件续至100 epoch后累计上限：**¥130且最多65 GPU小时**。金额或时长任一触顶即暂停，不自动扩预算。

关机安排：启动 GPU 前设置并回读约90分钟检查保险；吞吐确定后，按下一训练段预计耗时约1.25倍加15分钟重设保险，受授权预算约束。接近上限时提前在 epoch 边界保存并停机，避免依赖保险强制中断。已批准任务可连续运行；等待判断或授权时主动停机并回读 `Stopped`。大文件回收优先短无卡窗口。

## 4. 继续或停止条件

以下为单种子首轮筛选规则，不是统计显著性结论。

- **工程异常：**非有限 loss、持续AMP跳步、参数不更新、显存溢出或恢复失败，立即中止当前任务；仅最小修复实际阻塞，预算内重试。
- **30 epoch：**正常训练且无持续明显劣化则继续100。若ODG在20、30 epoch均落后约2个mIoU百分点以上，差距未收窄，并伴随类别或预测明显退化，则停机复核；不凭一个早期验证点停止。
- **100 epoch正向：**最近多个验证点持续提升，例如约≥0.5个百分点，且类别/预测或孔洞对照支持预期，申请300 epoch、mean消融、正式test和NYUv2验证。
- **100 epoch负向：**持续落后约≥1个百分点且无预期问题上的补偿收益，停止进一步训练。
- **基本持平：**收益零散或证据不足，停止追加费用并汇报，不自动扩展实验，不宣称方法有效。
