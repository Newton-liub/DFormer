# 论如何舆论攻击花而保苹（尤其对于情况1）

1. 钓鱼：假用情况3的情景转移，将花的情况假装套上苹的壳子去钓到A类人，截图其言论
2. 言论挑拨对立：正常人反A+正常人支持花（情况1），对这种正常人说：“切割” “前提是xxx对”
   1. 部分人扩大到全体人，不认就是切割。否定A偷换概念为否定A+正常人；情况3扩大到情况1，逼迫正常人不要就事论事
3. 同罪：因为有情况1，情况3，而A的错误判断，所以反击A来证明情况1苹的正确
4. 最终：用强调A的双标来兜底，无论事实如何，通过假装理中客反打。
