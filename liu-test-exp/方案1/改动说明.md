1. **立即冻结并归档当前 A2 v1，不得原地修改其科学语义。** 将 `MMFR-A2-train-integration-v1` 标记为 `superseded-before-formal-training` 或意思等价的状态，注明“因正式 500 epoch 尚未执行，所以在结果产生前进行协议修订”。不得修改其既有 protocol hash、历史 CPU/GPU preflight 事实、DVC/DVG 负结果。以现有文件为模板创建 `MMFR-A2-train-integration-v2`、`MMFR-A2-clean-control-v2` 和 `MMFR-A2-depth-corruption-train-v2`。**本任务不得启动云实例、500 epoch 训练、完整 evaluator 或 official test。**
2. **重写 A1/A2/B1 三阶段的科学含义，但暂时不要删除现有模块。** A1 定义为“synthetic failure generation + corruption-derived reliability surrogate”；A2 改写为“Depth corruption robustness training + parallel reliability estimation”，明确 A2 中 predicted reliability 不影响 segmentation backbone、decoder 或 geometry prior，因此 A2 的 segmentation gain 不能归因于 reliability head；B1 明确写成“第一个真正的 reliability-aware segmentation 阶段”，即首次让预测 reliability 影响 DFormerv2 的模型动作。把当前文档中类似“辅助 target 促进了 segmentation robustness”的表述删除。DFormerv2 的描述统一改成 **RGB-primary semantic path + Depth geometry-prior path 的非对称架构**，不要写成普通 RGB/Depth 双语义分支。DFormerv2 原论文明确将 Depth 作为 geometry prior，而不是像 RGB 一样显式编码。
3. **修正 A2 reliability target 对 MUSeg 原生无效 Depth 的定义。** 不修改 A1 v1 原有 synthetic burden 历史语义；在 A2 v2 中新增两个明确字段：`depth_valid_pre` 表示 corruption 前的真实输入有效性，定义为 `raw_depth_pre > 0 AND valid_mask`；`depth_valid_post` 表示 corruption 后实际输入有效性。令 A1 返回的 synthetic target 记为 RDsynR_D^{syn}，A2 v2 实际用于监督的 Depth reliability surrogate 改成
  RDsup(p)=VDpre(p)⋅RDsyn(p).R_D^{sup}(p)=V_D^{pre}(p)\cdot R_D^{syn}(p).
  因而 clean 样本中：原生有效 Depth 像素 target=1，原生 Depth=0 的无效像素 target=0；crop/pad 区仍保持 target 中性值 1，但继续由 `valid_mask` 排除。metadata 分开记录 `natural_invalid_pixels`、`synthetic_missing_pixels` 和 `post_corruption_invalid_pixels`，禁止把三者混为一类。这个修改有数据依据：MUSeg 作者明确保留了“Depth 信息缺失但 RGB 清晰”以及“RGB 较暗而 Depth 可靠”的样本用于 partial-modality-missing robustness research。
4. **A2 v2 只监督 Depth reliability，停止把 RGB 恒等于 1 当成有效 reliability 学习任务。** 为了不破坏 A1 未来 RGB/Depth 双通道 scaffold，可以保留两通道输出接口，但 A2 v2 的 reliability loss mask 只包含 Depth channel；RGB channel 不计入 loss、不报告 calibration 指标，也不得称为已训练的 RGB reliability estimator。B1-v1 同样只能消费 Depth reliability。未来只有进入 RGB corruption/B2 新 protocol 后，才能重新启用 RGB reliability supervision。
5. **增加一个必须通过的“gradient-path isolation qualification”，通过前禁止正式 A2 v2 训练。** 在完全相同的模型状态、输入 batch、corruption、RNG 和 segmentation loss 下，执行两次 backward：一次 `lambda_rel=0`，一次 `lambda_rel=0.1`。逐参数比较所有 DFormerv2 backbone/decoder/geometry-prior 参数的 gradient；它们必须在预定义浮点容差内相同，而 reliability head 参数只在后一种情况下产生有效梯度。再检查 segmentation logits 在 head 开/关时一致。若共享模型梯度发生变化，说明存在未记录耦合，立即阻塞。通过后在文档中明确：**A2 分割性能变化的直接原因是 corruption exposure，而 reliability head 在该阶段只承担 estimator qualification。** 这样当前阶段不需要额外浪费一次完整 500 epoch 的“corruption-only”训练来证明这个数学事实。
6. **统一 train/eval 中 spatial corruption 的尺度语义。** 保留当前“训练在最终 crop 后 corruption、评价在 original aligned grid 上先 corruption 再做 10-view”的总体数据流，但 `misalignment` 和 `blur` 不得继续以跨分辨率不等价的绝对像素参数定义 severity。v2 将 misalignment 改为相对宽高位移比例，再按实际 W,HW,H 换算 pixel shift；blur sigma 改成相对图像尺度的比例参数，再在实际 grid 上换算 sigma。noise 和 quantization 属于 intensity-space corruption，可维持其输入表示空间定义。protocol 中明确称这些为 **model-input/representation-level synthetic corruptions**，不要称为 Kinect 真实物理噪声模型。
7. **对 severity→corruption→burden 链做一次定点审计。** 对六种 failure 输出一张机器可检查的映射：`severity -> actual corruption parameter -> realized damage -> burden -> target`。重点检查 Gaussian noise、blur、quantization 是否存在“corruption 强度已经乘 severity，计算 burden 时又乘一次 severity”的二次编码。如果确实存在，A2 v2 默认修改为：severity 只控制 corruption 参数，continuous burden 由 realized normalized damage 本身产生，不再额外乘第二次 severity；misalignment burden 使用实际位移除以当前尺度允许的最大位移。要求 severity 增大时总体 burden 单调不减、target 总体单调不增。若代码实际不存在重复 severity，则保留现实现，只在审计报告中证明它不存在，禁止为了“看起来更合理”盲改。
8. **当前已经冻结且没有文献充分依据要求更改的项目一律保持。** `p_clean=0.25 / p_corrupt=0.75`、三阶段 curriculum、`max_specs=2`、`lambda_rel=0.1`、500 epoch、optimizer、LR、batch size、clean-only checkpoint selector、六单失效主 score、clean drop ≤0.50、paired location-group bootstrap 和主成功门槛全部保持，不因为新论文采用了 50% missing 等设置就照抄。KSTrack 的 50% modal-incomplete 是 tracking 场景，不能直接推出 MUSeg 最优 corruption ratio。 如果未来发现当前 exposure 不合适，只能新开 protocol，不能看完结果后修改 v2。
9. **现在就建立并冻结 reliability supplemental protocol，不要等 A2 结果出来以后再挑指标。** 建议 identity 为 `MMFR-R1-reliability-supplemental-v1`。它必须独立报告三层问题：第一层，Depth surrogate target fidelity，固定报告 MAE 和 Brier score；第二层，reliability 与实际 segmentation risk 的关系，固定报告 reliability-error monotonicity、risk-coverage curve 和 AURC；第三层，下游 gain，只能等 B1 后用 segmentation 指标回答。第一、二层不得替代主 robustness score。Reliability 结果还必须分成 `explicit-invalid`（entire missing、spatial dropout、misalignment 越界）和 `implicit-quality`（noise、blur、quantization、misalignment 有效区）两组报告，因为前一组可以通过 `depth_valid` 非常容易识别，不能用它掩盖后者识别失败。
10. **增加一个结果前冻结的 severity-response supplemental evaluator，但不得改变当前主 score。** 建议 identity 为 `MMFR-S1-severity-sweep-v1`。对 `spatial_dropout / gaussian_noise / blur / quantization / misalignment` 固定评价 severity `0.25、0.50、0.75`，另加 `entire_missing@1.0` 和 clean；报告每类 mIoU-vs-severity 曲线、五类非完全缺失 corruption 的宏平均 robustness-AUC，并检查性能是否总体随 severity 恶化。不得用于 checkpoint selection，也不得用它在主门槛失败后重新定义“成功”。这样做有充分文献依据：CMCAF专门做了 controlled degradation levels，展示模型随退化强度变化的稳定性；Yu 等也按 missing-modality ratio α\alpha 做曲线，而 KSTrack 测了随机 missing rate。
11. **重写 B1 规划；当前** `mean/std reliability -> global scale` **的 adapter 只能保留为最小 baseline，不得作为最终 B1 默认方案。** 将它重命名为类似 `B1a-global-reliability-baseline`。正式 B1 的设计原则冻结为：reliability 是“condition”，fusion action 必须由 segmentation objective 学出来，禁止令 action 直接等于 reliability 或 corruption mask；adapter 至少同时接收 stage-specific Depth reliability 和 DFormerv2 当前 stage 的语义/context 信息；局部失效情况下必须保留 spatial reliability structure，不能只留下 mean/std。优先研究 **DFormerv2-native reliability-conditioned geometry adaptation**：让 reliability/context 调节 Depth–Spatial prior 的融合强度或 GSA 中 geometry prior 的影响，而不是直接 hard-off Depth contribution。所有新调制层必须 zero-init/no-op-init，使初始化时旧 DFormerv2 行为严格不变，并使用连续软调制而非 0/1 硬开关。这个选择与新文献一致：GEM 的 dynamic scalar/mask weighting 是端到端任务学习的，而且作者发现直接 selective switching-off 反而伤性能； CMCAF 也采用 `(1+gate)` 的有界残差式条件调制以保护主 RGB 语义。 当前 DVG Oracle 的负结果因此继续保留，它恰好说明“知道哪里坏”不等于“知道模型该采取什么动作”。
12. **B2 继续与 B1 严格分离，不要趁这次修改塞进 A2/B1。** 把 B2 的候选路线从原先笼统的“Depth semantic path / dual semantic path”扩写成三个预研选项：`B2a explicit Depth semantic fallback`、`B2b feature reconstruction/compensation`、`B2c modality-agnostic representation/pretraining`。默认首先研究 B2a，因为对当前 DFormerv2 改动最可控；KSTrack 的 prototype + feature reconstruction 可作为 B2b 的直接参考， Yu 的 modality-asymmetric reconstruction 则作为 B2c 参考。 不要把 CMNeXt 当成解决 RGB-complete-missing 的直接模板，因为 CMNeXt 本身明确建立在“RGB representation is essential”的 primary RGB branch 假设上。
