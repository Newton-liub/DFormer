## 【J2-1】研究方案设计专用提示词｜DFormerv2-S 后验校准方案（项目适配版）

# 项目适配说明／状态边界

## 1. 本方案的研究对象

本方案面向当前 DFormer 项目的 MUSeg 阶段二，主研究对象固定为：

- **模型**：本项目 `DFormerv2-S + ham`；
- **任务**：MUSeg 15 类 RGB-D 语义分割；
- **输入**：对齐的 RGB 与 Depth；
- **输出**：与输入空间尺寸对应的 15 类逐像素 logits；
- **当前配置尺寸**：480×640；
- **训练定位**：阶段二计划建立最长 500 epochs、三随机种子的正式 baseline。

这里的 baseline 是**本项目目标 baseline**，用于支撑后续最小可验证实验（MVE）与后验校准研究；不将其表述为 MUSeg 论文中 DFormer-S 数值的严格复现。若未来需要严格复现论文 DFormer-S，必须另立配置、训练与验收协议，不属于本方案。

## 2. 状态边界

本文仅做研究方案设计，不代表实验已经执行。

### 现有能力与已确认事实

1. `local_configs/MUSeg/DFormerv2_S_MVE.py` 已定义 MUSeg 数据配置、15 类、480×640、`DFormerv2_S` 骨干和 `ham` 解码器。
2. `models/builder.py` 已能构建 `DFormerv2_S`，接收 RGB 与辅助模态输入，并将解码输出插值到输入空间尺寸；无标签推理时返回逐像素 logits。
3. `models/encoders/DFormerv2.py` 提供本项目 DFormerv2 系列 RGB-D 编码实现。
4. 现有 A2 工具可以作为 **Depth 局部置零／敏感性 pilot** 的基础：它读取 RGB、Depth、标签与掩码，对掩码区域的 Depth 置零，并调用冻结 checkpoint 推理。它不等于完整退化套件。
5. 阶段二的开发划分协议 ID、分组语义和候选生成算法已经冻结，但协议实现、真实候选生成、审计、用户门禁 A、训练链路改造、长程训练、正式三种子 baseline 与后续 A2 均未完成。

### 拟新增但尚未实现的离线模块

1. 冻结 checkpoint 的 float32 logits 导出与一致性核验工具；
2. 独立 calibration 集协议及其冻结、审计记录；
3. 温度缩放、类别条件缩放、向量缩放、顶层置信度保序回归等离线校准器；
4. ECE、NLL、Brier Score、可靠性图、风险—覆盖曲线与 AURC 的离线评价工具；
5. 高置信错误、边界风险和区域风险的离线分析工具；
6. 在现有 A2 pilot 之外扩展的退化生成与审计工具。

这些模块均应位于冻结模型之外，不修改 DFormerv2-S 融合骨干，也不反向改变正式 checkpoint。

### 后续可选扩展

1. 严格 RGB-only 或 Depth-only 模型机制对照；
2. 退化质量条件化校准；
3. 跨矿井泛化或留一矿井实验；
4. 区域级拒识与整图复核排序；
5. 退化增强训练或其他非纯后验方法。

可选扩展需要另立配置、数据隔离和训练／评价协议，不作为主实验的前置条件，也不得写成当前已具备能力。

## 3. 与阶段二门禁的硬衔接

1. MUSeg 官方 `train.txt=1595`，官方 `test.txt=1576`。
2. 官方 test 在开发期封存，不参与 split 目标、epoch、超参数、seed、checkpoint、校准器、阈值或退化条件选择。
3. 先按已经冻结的 `MUSEG-DEV-SPLIT-PROTOCOL-1` 完成 group-aware 的 train-dev/val-dev 候选生成、审计、复核和用户门禁 A。本文不修改该协议，也不另行规定当前阶段 split 比例。
4. 在冻结开发划分之后，按阶段二顺序完成训练／checkpoint／resume 链路、长程开发 baseline、正式协议冻结、三随机种子正式 baseline 和正式 checkpoint。
5. 正式校准实验所需的**独立 calibration 集**属于后续协议扩展，需在正式校准实验前另行冻结。现有 val-dev 承担模型选择与开发验证职责，不能直接改称或复用为 calibration 集。
6. 当前 MVE 配置仍把评估源指向官方 test；阶段二计划已经要求在长程开发训练前纠正该问题。本方案不借校准任务绕过该门禁。

# 第一部分：研究问题与假说

## 1. 项目事实与文献依据分离

### 项目事实

本项目将以 `DFormerv2-S + ham` 的 RGB-D 输出为唯一主研究对象。模型在 RGB 与 Depth 输入上产生 MUSeg 15 类逐像素 logits，后验校准只消费冻结 checkpoint 的输出，不参与融合特征学习。

### 文献依据

- MUSeg 为矿下 RGB-D 语义分割及 15 类像素级标注提供数据基础。[RE429]
- 既有矿下 RGB-D 研究通常侧重 PA、mPA、mIoU、边界或语义连贯性，可信度评价可作为补充维度。[RE165]
- 安全关键感知研究强调概率可靠性、高风险预测过滤与复核门控，但这些结果不能直接外推为本项目的安全保证。[RE068, RE131, RE226]
- 后验校准可在冻结模型外拟合概率映射或风险门控，这是本方案采用离线工具路线的文献动机。[RE136, RE226]
- 注意力、融合权重和模态可靠性建模不天然等于概率已经校准。[RE119, RE130, RE659]

文献结论只用于提出研究问题；本项目模型、配置、门禁与完成状态以仓库事实和阶段二协议为准。

## 2. 核心矛盾

1. **分割准确率不等于概率可信。** 较高 mIoU 不能保证 0.9 的像素置信度确实对应约 90% 的正确率。
2. **概率校准不等于错误排序改善。** 单调校准可能降低 ECE，却不改变风险—覆盖排序，因此 AURC 可能保持不变。
3. **正常条件有效不等于退化条件有效。** 低照、模糊、Depth 空洞、遮挡、模态缺失、错位和复合退化可能导致校准迁移衰减。
4. **像素平均不等于空间风险可控。** 连续错误区域、边界错误或小目标错误可能被大量容易像素稀释。[RE165]

## 3. 核心科学问题

在冻结 `DFormerv2-S + ham` checkpoint 的前提下：

1. 后验校准能否改善正常条件下像素置信度与实际正确率的一致性？
2. 校准收益能否迁移到拟扩展的输入退化条件？
3. 校准后的风险分数是否能有效排序错误，从而改善风险—覆盖表现？
4. 像素级风险是否会掩盖连续错误区域，区域风险能否提供互补信息？
5. 若未来开展跨矿实验，源域冻结的校准器能否保持收益，其失效边界在哪里？

拒识在本文中只表示“像素、区域或图像需复核”，不等同于车辆控制安全、人身安全或真实传感器故障概率。

## 4. 可证伪假说

- **H1：概率校准有效性。** 至少一种后验方法能在独立评价数据上改善 ECE、NLL 或 Brier Score；其中全局温度缩放原则上保持逐像素 argmax，因此不应改变分割结果。
- **H2：阈值迁移有效性。** 在独立 calibration 集上冻结的风险阈值，能在未参与选择的评价数据上更接近预设风险约束，或在相同风险下保留更高覆盖率。
- **H3：校准与排序相互独立。** 保序校准可以改善概率数值，但不必改善 AURC；只有改变错误相对排序的风险分数才可能改善 AURC。
- **H4：退化迁移存在边界。** 正常条件拟合的校准器在单退化下可能仍有效，在复合退化或严重错位下可能衰减或反转。
- **H5：区域风险具有补充价值。** 区域聚合可能更容易发现空间连续错误和边界错误，但其收益必须以覆盖代价和误拒率共同验证。

# 第二部分：实验对象与对照边界

## 1. 主模型

主实验只使用本项目正式训练并冻结的 `DFormerv2-S + ham` RGB-D checkpoint：

- RGB 和 Depth 共同输入；
- 模型输出 15 类逐像素 logits；
- 输入与评估尺寸遵循当前项目 480×640 配置；
- 正式 checkpoint 来自阶段二长程 baseline 与三随机种子计划；
- checkpoint 选择必须在官方 test 封存条件下完成；
- 不为获得更好的校准结果重新训练或微调融合骨干。

三随机种子用于评价基础模型训练波动。每个正式 seed 的校准器应基于该 seed 的冻结 logits 独立拟合，不能挑选单个最有利 seed 代表总体。[RE130]

## 2. 模态对照的正确解释

### 主研究对象

`DFormerv2-S` RGB-D 是唯一主研究对象。

### 缺失模态退化

- 将 RGB 输入置为全零，只表示 **RGB 缺失模态退化**；
- 将 Depth 输入置为全零，只表示 **Depth 缺失模态退化**。

这两种条件仍然调用已经按 RGB-D 训练的融合模型，因此不能称为严格的 RGB-only 或 Depth-only 模型。

### 可选的严格单模态模型

严格 RGB-only、Depth-only 机制对照需要：

1. 另立模型配置；
2. 明确输入与网络结构；
3. 另行冻结训练、模型选择和 checkpoint 协议；
4. 在相同数据隔离下独立训练和评价。

它们只作为后续可选机制对照，不是开展 RGB-D 后验校准主实验的前置条件。涉及单模态冲突分数的分析也必须等待严格单模态模型存在后再开展，不得用全零退化结果冒充单模态概率。原文涉及的通用分割架构文献仅保留为可选机制背景，不作为用其他骨干替换本项目 DFormerv2-S 的依据。[RE060]

## 3. 校准方法对照

主方案保留以下离线方法：

1. 未校准 Softmax；
2. 全局温度缩放；
3. 类别条件温度缩放；
4. 向量缩放；
5. 顶层置信度保序回归；
6. 可选的退化质量条件化校准。

全局温度缩放作为最低复杂度基线。类别条件缩放、向量缩放和条件化校准具有更高自由度，只有在独立 calibration 集规模与类别覆盖足以支持时才进入正式比较；其正则、回退规则和选择标准需在实现前另行冻结。[RE078, RE119, RE136]

保序回归仅映射“预测类别正确概率”，不虚构完整 15 类概率，因此不能与完整概率校准器直接比较多分类 NLL。[RE136, RE226]

## 4. 拒识与风险分数对照

拟比较：

1. 不拒识；
2. 未校准最大后验概率；
3. 校准后的预测类别正确概率；
4. 预测熵；
5. 区域聚合风险；
6. 仅用于分析上界的 oracle 错误排序。

oracle 只衡量可达到的排序上界，不作为部署方法。所有阈值或工作点只能在独立 calibration 数据上冻结，不能根据官方 test 或最终退化结果回调。[RE131, RE226, RE068]

# 第三部分：数据隔离与阶段前置条件

## 1. 阶段二开发划分

严格沿用已经冻结的阶段二 01 协议：

1. 从官方 train 的 1595 张图中按 location group 构建 train-dev/val-dev；
2. 同一 location group 不跨 split；
3. 官方 test 的 1576 张图开发期封存；
4. split 生成、统计、审计、Sol 复核与用户门禁 A 完成前，不进入训练链路；
5. 本方案不修改 frozen protocol，不增加或替换当前阶段 split 比例。

## 2. calibration 集的后续扩展

后验校准需要与训练及模型选择数据职责分离的独立 calibration 集。该集合尚不存在，正式校准前必须另立并冻结协议，至少明确：

- 数据来源与允许用途；
- group-aware 防泄漏约束；
- 与 train-dev、val-dev、官方 test 的关系；
- checkpoint、校准器和阈值各自允许查看的数据；
- 列表、哈希、审计和用户门禁。

这里不预设具体比例，也不把 val-dev 直接改作 calibration。若未来协议需要从现有开发数据中扩展，必须先处理模型选择与校准职责冲突，再冻结新的清单；不能在得到结果后追溯调整。

数据隔离思想与独立条件可靠性评价可参考既有校准和门控研究。[RE136, RE131, RE226]

## 3. 官方 test 与最终评价

官方 test 的解封继续受阶段二门禁 F 控制。三个正式 seed 的预定 checkpoint、哈希与运行状态合格后，才由用户明确批准一次性 test 评价。后验校准方案不得把官方 test 变成校准集、阈值选择集或退化参数选择集。

跨矿实验属于可选扩展。只有矿井身份、分组边界、源／目标域隔离和校准职责另行冻结后，才可使用“跨矿泛化”或“留一矿井”结论；当前不把该实验写成已经完成或主实验必需步骤。

# 第四部分：退化研究设计

## 1. 现有能力的准确边界

现有 A2 仅能作为 Depth 局部置零与敏感性分析的 pilot 基础。它表明项目已经具备“按掩码修改 Depth、加载 checkpoint、执行 RGB-D 推理并输出预测／分割指标”的局部链路，但不能据此宣称已经实现：

- 完整退化生成套件；
- 完整校准 logits 导出；
- 多退化统一 manifest；
- 校准与风险评价；
- 正式长程 baseline 上的退化结论。

历史 pilot 结果也不能替代阶段二正式 checkpoint 上的实验。

## 2. 拟扩展退化条件

在正式 baseline 和独立 calibration 协议完成后，可逐步扩展：

1. RGB 低照；
2. RGB 模糊；
3. Depth 局部空洞；
4. RGB 或 Depth 局部遮挡；
5. RGB 整模态缺失；
6. Depth 整模态缺失；
7. RGB-Depth 错位；
8. 复合退化。

退化类别的研究动机分别可参考质量感知、缺失模态、遮挡和弱标定研究。[RE752] [RE346, RE461] [RE438] [RE460]

本设计阶段不新增强度、核大小、遮挡比例、错位像素、组合清单等实现参数。正式实现前应基于文献全文、项目输入定义与 pilot 结果另行预注册，且不得用最终测试表现倒推有利参数。

## 3. 退化实验控制原则

1. 正常与退化版本必须来自同一原始样本并共享标签；
2. 退化生成记录样本身份、条件与配置，保证可审计；
3. 校准器、风险阈值和退化条件的选择互相隔离；
4. 全零 RGB／Depth 只标记为缺失模态退化；
5. 合成退化结果不外推为真实粉尘浓度、设备寿命或物理故障概率；
6. 已知退化和未见复合退化的用途需在实现前冻结。

质量自适应和模态可靠性研究可作为后续条件化校准的动机，但不证明当前模型已有对应能力。[RE955, RE752, RE119]

# 第五部分：冻结 logits 与后验校准

## 1. logits 采集原则

后验校准必须建立在冻结 checkpoint 与**同一批 float32 logits**上：

1. 每个正式 checkpoint 固定模型权重、推理配置和输入清单；
2. 对每个样本保存或可审计地重建 15 类逐像素 float32 logits；
3. 各校准方法读取同一份 logits、标签和有效像素掩码；
4. 校准比较不得因重复推理、混合精度差异或样本过滤差异产生输入不一致；
5. `ignore index` 像素不参与分割、校准或拒识指标；
6. logits 产物记录 checkpoint、split、配置和生成命令的可追溯标识；
7. 校准器只在独立 calibration 集拟合，随后冻结并应用到预定评价条件。

概率输出和不确定性评价的研究动机来自安全关键感知与校准工作。[RE131, RE136, RE666]

## 2. 全局温度缩放

设冻结 logits 为 $z_{i,c}$，温度为 $T>0$：

$$
p_{i,c}(T)=\frac{\exp(z_{i,c}/T)}{\sum_{k=1}^{15}\exp(z_{i,k}/T)}.
$$

温度仅在独立 calibration 集上通过预先冻结的目标拟合。拟合后不针对官方 test、具体矿井或某个退化条件重新调节。由于正温度对同一像素各类别 logits 做统一缩放，argmax 应保持不变；实现时需要核验预测标签和 mIoU 的一致性。[RE136, RE226]

本阶段不冻结优化器、迭代次数、温度范围或采样规模，这些属于离线工具实现前的协议事项。

## 3. 类别条件温度与向量缩放

类别条件温度和向量缩放用于检验类别差异与更高自由度映射：

$$
z'_{i,c}=a_c z_{i,c}+b_c.
$$

正式开展前必须明确训练—推理定义、参数约束、正则、类别覆盖不足时的处理和模型选择规则。若方法改变 argmax，必须同时报告改变像素比例、每类 IoU 与 mIoU，不能把它描述成“分割完全不变”的纯温度校准。[RE078, RE119, RE136]

## 4. 顶层置信度保序回归

以最大后验概率 $s_i$ 和正确性标签 $r_i=\mathbb{1}(\hat y_i=y_i)$ 拟合单调映射：

$$
f(s_i)\approx P(r_i=1\mid s_i).
$$

该方法只产生预测类别的正确概率，可用于顶层 ECE、可靠性图和选择性拒识。因为映射保序，风险—覆盖排序与 AURC 通常不变；若 ECE 改善但 AURC 不变，应解释为“概率值改善、排序未改善”，而不是失败。[RE136, RE226]

## 5. 正常条件与混合条件校准

优先研究只用正常条件独立 calibration 数据拟合的校准器，以检验其向退化条件迁移的能力。混合退化校准器、按质量条件化校准器或按退化类型分别拟合的校准器均属于可选扩展；其数据组成与使用条件必须另行冻结。若推理时需要真实退化标签选择校准器，应标记为 oracle 条件化分析，而不是直接部署方案。[RE955, RE752, RE119]

# 第六部分：评价体系

## 1. 基础分割性能

对冻结模型及可能改变 argmax 的校准方法报告：

- PA、mPA；
- 每类 IoU 与 mIoU；
- 必要时的边界区域 IoU。

全局温度缩放和顶层保序映射若不改变类别预测，其分割指标应保持一致。文献中的矿下语义分割指标仅作为评价动机，不替代本项目正式实验结果。[RE429, RE165]

## 2. 概率校准

保留以下研究指标：

- ECE；
- 自适应分箱 ECE；
- 类别条件 ECE；
- NLL；
- 多分类 Brier Score；
- 可靠性图。

NLL 与多分类 Brier Score 只用于具有完整 15 类概率输出的方法。分箱、聚合单位、类别不足处理与置信区间方案在工具实现前另行冻结，不在当前设计中写死。[RE666, RE131, RE226]

Brier Score 可写为：

$$
\mathrm{Brier}=\frac{1}{N}\sum_i\sum_c\left(p_{i,c}-\mathbb{1}(y_i=c)\right)^2.
$$

## 3. 风险—覆盖与 AURC

对风险分数 $q_i$，定义接受集合：

$$
A(\tau)=\{i:q_i\ge\tau\}.
$$

覆盖率与选择性风险分别为：

$$
C(\tau)=\frac{|A(\tau)|}{N_{\mathrm{valid}}},
\qquad
R(\tau)=\frac{\sum_{i\in A(\tau)}\mathbb{1}(\hat y_i\ne y_i)}{|A(\tau)|}.
$$

正式报告应包含风险—覆盖曲线、AURC、固定覆盖率风险，以及 calibration 集冻结阈值在独立评价条件下的实际风险和覆盖率。具体覆盖率点、目标风险和阈值选择规则尚未冻结，留待离线工具协议确定。[RE131, RE226, RE068]

## 4. 高置信错误

保留两种互补口径：

$$
\mathrm{HCE}_{all}(t)=
\frac{\#\{i:\hat y_i\ne y_i,q_i\ge t\}}{N_{\mathrm{valid}}},
$$

$$
\mathrm{HCE}_{conf}(t)=
\frac{\#\{i:\hat y_i\ne y_i,q_i\ge t\}}{\#\{i:q_i\ge t\}}.
$$

阈值必须在正式分析前冻结，不能依据最终结果选择。结果可按类别、矿井、退化和边界／内部像素分层，但跨矿分层仅在对应协议完成后开展。[RE068, RE226]

## 5. 统计单位与多随机种子

1. 正式结果覆盖阶段二预定的三个基础模型随机种子；
2. 不以单个最好 seed 代替总体结论；
3. 校准器对每个冻结 checkpoint 分别拟合；
4. 重采样和置信区间以图像或 location group 为单位，避免把像素错误视为完全独立；
5. 比较同一批 logits 上的方法时使用配对分析；
6. 具体 bootstrap 次数、显著性检验和多重比较规则在实现前冻结。

多随机种子与分层不确定区间的研究动机参考相关 benchmark 和稳定性工作。[RE130, RE447]

# 第七部分：区域风险与机理分析

## 1. 区域风险

区域风险用于检验像素平均指标是否掩盖连续错误块，作为像素级结果的补充，而非替代：

1. 区分标签边界与内部像素；
2. 从预测结果中提取同类连通区域；
3. 聚合区域内像素风险；
4. 定义可审计的区域正确性或区域匹配规则；
5. 报告区域覆盖率、错误区域拒识率、正确区域误拒率和区域 AURC；
6. 若区域定义对参数高度敏感，只报告为探索性分析。

边界宽度、连通性、最小区域面积、匹配阈值和聚合函数尚未冻结，需在离线模块设计时预注册，不在当前方案中填入未经项目验证的数值。区域与边界研究动机来自矿下语义连贯性和不确定性过滤工作。[RE165, RE068, RE131]

## 2. 质量—冲突—失校准机制

可在主校准结论之后探索：

- RGB 质量与失校准的关系；
- Depth 有效率与高置信错误的关系；
- RGB-Depth 对齐质量与校准迁移的关系；
- 若未来严格单模态模型已训练，再研究跨模态预测冲突。

质量感知、特征匹配、异质性与不确定性加权可作为方法线索。[RE752, RE955, RE415, RE078, RE119, RE659]

具体质量公式、边缘容差、分层数量和统计模型都属于后续可选扩展。当前不把它们写成已实现，也不以全零输入退化替代严格单模态概率来计算冲突。

# 第八部分：结果判定与证伪规则

## 1. “校准有效”

只有在未参与拟合与选择的独立评价数据上，ECE、NLL 或 Brier Score 等预注册指标得到稳定改善，才支持概率校准有效。calibration 集自身改善不能作为独立证据，可靠性图用于辅助检查指标是否被样本分布掩盖。

## 2. “不损害分割精度”

- 全局温度缩放应保持 argmax 与分割指标；
- 向量缩放等可能改变 argmax 的方法必须报告分割变化；
- 不预先填写尚未冻结的精度容忍阈值。

## 3. “选择性拒识有效”

ECE 改善不自动证明 AURC 改善。只有风险—覆盖结果或冻结阈值在独立评价数据上表现更好，才能支持拒识有效；若风险约束频繁被违反，应报告阈值迁移失败。

## 4. “退化鲁棒”

正常、单退化和复合退化应分别报告，不能只给所有条件平均值。退化强度与组合必须事前冻结；合成退化只能支持对应合成条件的结论。

## 5. “跨矿泛化”

跨矿实验尚未开展。只有完成矿井身份核验、group-aware 隔离和独立 calibration 协议后，才能报告各目标矿井、宏平均与最差矿井结果。

## 6. 停止或降级条件

出现以下情况时停止对应高自由度实验或降级为探索性分析：

1. 阶段二正式 baseline、三随机种子或 checkpoint 尚未验收；
2. 独立 calibration 集尚未冻结；
3. logits 无法证明来自同一冻结 checkpoint、同一输入清单和 float32 输出；
4. calibration 数据类别覆盖不足以支撑类别条件方法；
5. 区域结论对未冻结参数高度敏感；
6. 校准在未见退化下失效。

第 6 项本身可以成为“校准迁移边界”的研究结论，不应通过回调最终评价阈值掩盖。

# 第九部分：预期贡献与叙事结构

## 1. 预期贡献

若实验支持假说，本研究可形成：

1. 面向本项目 `DFormerv2-S + ham` 的训练、模型选择、独立校准与评价隔离方案；
2. 对概率校准、错误排序和阈值迁移三类结论的明确区分；
3. 对正常、缺失模态和拟扩展退化条件下可信度边界的系统评价；
4. 像素风险与区域风险的互补分析。

本研究不主张提出新的校准理论，也不把 DFormerv2-S baseline 表述为 MUSeg 论文 DFormer-S 的严格数值复现。

## 2. 论文叙事建议

1. 先建立并验收本项目正式 RGB-D baseline；
2. 再证明未校准置信度在正常或退化条件下是否存在问题；
3. 区分概率值、错误排序与阈值迁移；
4. 比较温度缩放、向量缩放和保序回归；
5. 报告风险—覆盖与区域风险；
6. 最后讨论退化和可选跨矿扩展中的成功与失败边界。

潜在结论应保持可证伪表述：简单后验校准可能改善同域概率可信度，但不自动改善错误排序，其风险阈值在跨退化或跨矿分布偏移下可能存在迁移边界。

# 与本项目阶段二的衔接和实施顺序

## A. 现有能力

1. 已有 `DFormerv2-S + ham` 的 MUSeg 15 类、480×640 RGB-D 配置与逐像素 logits 推理链路；
2. 已有 A2 Depth 局部置零／敏感性 pilot 基础；
3. 已冻结阶段二 01 的开发划分协议决策。

这里的“已有”不包含新 split、长程训练结果、正式三种子 checkpoint、校准器或完整退化套件。

## B. 必须先完成的阶段二前置工作

1. **完成 01，而不仅是读取冻结决策**：实现 group-aware split 工具，生成唯一候选，完成审计、Sol 复核和用户门禁 A；
2. 完成训练验证、checkpoint、best/latest 与 resume 链路改造；
3. 完成三随机种子编排与 GPU qualification；
4. 在 train-dev/val-dev 上完成最长 500 epochs 计划下的长程开发 baseline，并只依据 validation 冻结训练周期和 checkpoint 选择规则；
5. 按冻结协议完成三随机种子正式 baseline 与正式 checkpoint；
6. 继续遵守官方 test=1576 的封存和门禁 F，不让校准任务提前使用 test。

## C. 拟新增离线校准阶段

阶段二正式 checkpoint 验收后，才新增以下工作：

1. 另立并冻结独立 calibration 集协议；
2. 建立 float32 logits 导出、哈希与一致性核验；
3. 在同一批 logits 上拟合未校准、温度缩放、向量缩放与保序回归等方法；
4. 建立 ECE、NLL、Brier、风险—覆盖、AURC、高置信错误和区域风险工具；
5. 冻结校准器、风险阈值与正式评价协议；
6. 在不修改融合骨干的前提下运行正式离线比较。

## D. 可选扩展

主校准结果稳定后，再决定是否开展：

1. 基于现有 A2 pilot 扩展低照、模糊、Depth 空洞、遮挡、单模态缺失、错位与复合退化；
2. 严格 RGB-only／Depth-only 模型训练与机制对照；
3. 条件化校准；
4. 跨矿实验；
5. 更完整的区域或整图复核研究。

以上扩展均需独立门禁或协议，不改变已经冻结的阶段二 01 协议，不作为主实验启动条件，也不得在实施前写成已完成。
